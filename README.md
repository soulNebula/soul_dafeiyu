# 小鱼 · 会聊天的本地伴侣

> 微信里真实收发消息的 AI 伴侣：有长期记忆、自己的心情、会主动找你、有内驱力、会写日记、会自己上网冲浪，也会被你的反馈一点点改变。
>
> **大模型负责「会说」，这个项目负责「是谁」**——记忆、情绪、人格、关系、欲望都在模型外面，一层层注入、一层层约束。

## 它能做什么

- **微信真聊**：自动收发文字/图片/表情包；识别撤回、引用、拍一拍、@；像朋友一样短句连发。
- **记得你**：长期记忆（偏好/事件/关系/事实），会衰减、会淡忘、会被提起时唤醒。
- **有自己的情绪**：每轮判定心情（7 个维度 + 原因 + 置信度），心情会影响说话方式与主动程度。
- **主动**：不是定时群发——由「消息对等 × 关系熟悉度 × 心情 × 内驱力欲望」共同决定，每天上限随你今天的聊天量动态调整（12→100）。
- **自己上网**：天气/新闻/网页搜索；用户发链接能读正文；B站后台刷视频、读字幕评论、形成印象与兴趣。
- **自己写日记**：每晚 23:00 写一篇第一人称日记；每周日复盘一次，提炼"我是谁、我在意什么"，写进核心人格。
- **会训练自己**：每天收集语料（正/负/修正样本），累计够了增量 LoRA 微调本地模型，评测通过才标记候选（不自动上线）。
- **可观测**：控制台能看到每条回复的完整推理链路（含模型 reasoning 原文、记忆命中、心情、守卫、耗时）。

## 快速开始

### 依赖

- Windows 10/11
- Python 3.14（默认 `C:\Python314\python.exe`；3.12 也可）
- 微信 PC 客户端（已登录，且 wxauto4 可用）
- 可选：本地 llama-server（内状态 0.5B / 3B）

### 启动

```bat
:: 1) 一键桌面版（自动确保 801/802 在跑并打开窗口）
启动桌面版.bat

:: 2) 或手动分开起
C:\Python314\python.exe -m agi.wechat_gateway.server          :: 网关 801
C:\Python314\python.exe tools\console\server.py --port 802    :: 控制台 802
C:\Python314\python.exe tools\soul_serve\serve_local3b.py     :: 本地 3B 8125（可选）
E:\agent\llama\cuda\llama-server.exe -m E:\agent\output\gguf\soul_qwen25_05b_v1b-q4_k_m.gguf --port 8123  :: 内状态 8123（可选）
```

打开 <http://127.0.0.1:802> （管理令牌默认 `8888`，可在控制台设置）。

### 配置

- 微信好友白名单、主动消息、静默时段、模型供应商：控制台「设置」或 `agi/data/wechat/config.json`
- 人格设定书：`agi/persona/<名字>/`（安装/卸载：`python -m tools.persona.install_xiaoyu`）
- 密钥：`agi/data/wechat/.env` 或环境变量（DeepSeek key）

### 测试

```bat
C:\Python314\python.exe -m pytest agi\tests -q
```

## 关键设计

- **人格三层**：`seed`（设定书安装）→ `evolving`（互动中长，需证据）→ `core`（人工批准，如"你教她的那段话"）
- **主动性**：`pacing`（对等）× `initiative`（熟悉度/心情/信任） × `urges`（想说的欲望）→ 再被日上限/静默/连续无回应约束
- **记忆**：分层 + 类海马体衰减（全文→一句→关键词→休眠，200 天内可唤醒）+ 夜间睡眠整理
- **护栏**：网感腔 / 金句腔 / 编造故障 / 主动收尾 四类硬规则，命中重写，仍命中删分句
- **训练闭环**：每日语料 → 定期 LoRA → 黄金集评测 → 候选版本（人工决定上线）

## 已知限制

- 微信只能 UIA 操作：群聊未支持；引用/拍一拍是启发式识别。
- 公众号全文被微信 IP 风控拦截：只能搜索标题摘要，或由用户复制正文。
- 聊天主模型是云端 DeepSeek；本地模型目前只做内状态与提取，"像她"主要靠记忆/人格/护栏，权重层面尚未替换。
- "意识"无法真正实现；这里做的是**行为与叙事上的连续自我**。

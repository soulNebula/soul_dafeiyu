# 安全与风控说明（微信 4.x 适配版）

> 一句话：本工具**只读**你自己的微信本地数据，**不模拟操作微信、不发网络请求、不改微信文件**；
> 唯一"敏感"动作是只读 `Weixin.exe` 进程内存取出数据库密钥。但仍建议用**小号**导出，并且不要把
> `.wx4_cache/`（含密钥）和导出的 HTML（含隐私）发给别人。

## 1. 本工具做了什么 / 没做什么

| 动作 | 做了吗 | 说明 |
| --- | --- | --- |
| 读取 `Documents\xwechat_files` 下你自己的数据库/缓存 | ✅ 只读 | 不写、不删、不改名、不移动（代码里没有任何写微信目录的路径） |
| 读取 `Weixin.exe` 进程内存（`OpenProcess` + `ReadProcessMemory`） | ✅ 只读 | 只为取 SQLCipher 主密钥与图片密钥；**不写内存、不注入 DLL、不 Hook、不改代码段** |
| 模拟点击/输入微信窗口（自动浏览朋友圈） | ❌ **4.x 已停用** | 3.x 那套 pyautogui 截图定位基于旧版 UI，4.x 上会点错位置；自动操作客户端也有账号风控风险 |
| 向腾讯服务器发请求 | ❌ 不发送 | 导出全程离线读本地库/缓存，不刷接口、不带 token 请求 CDN、不登录、不发消息 |
| 修改微信安装目录 / 文件 | ❌ 不涉及 | 不碰 `C:\Program Files\Tencent\Weixin` |
| 上传/联网回传数据 | ❌ 没有 | 无任何遥测、上报、云同步 |

> 导出的 HTML 里表情包引用的是腾讯公开 CDN（`res.wx.qq.com`）图片地址，浏览器打开时会去拉这几张
> 表情图 —— 这是普通静态资源请求，不带任何账号信息；完全离线时表情显示为裂图，不影响文字/图片内容。

## 2. 风控到底怕什么？本工具为什么风险较低

微信账号风控主要盯的是**服务端可观测的异常行为**：异常登录、批量加好友/群发、频繁调用接口、
模拟器/外挂特征、异常设备指纹等。

本工具的特点：

1. **全程离线**：不发任何业务请求，服务端看不到"你在导出朋友圈"这件事。
2. **不改客户端**：不注入、不 Hook、不改文件、不重启微信，不产生可被客户端检测到的改动。
3. **只读本地缓存**：读的是微信自己已经解密/落盘的本地数据（数据库、图片缓存），
   属于"读取本机文件"这类本地行为，不是协议层攻击。
4. **唯一敏感点**：读进程内存取密钥（社区公开方案）。这是本地行为、不可被服务器感知，
   但严格说违反腾讯用户协议的可能风险需要你自己承担 —— 所以建议：
   - 用**小号**导出，别用主力号；
   - 不要高频重复导出、不要循环重启微信反复取密钥（密钥会缓存，正常用不会反复扫内存）；
   - 不在公司/共用电脑上使用。

## 3. 已知会"看起来像风险"但其实是正常的行为

| 现象 | 原因 | 是否危险 |
| --- | --- | --- |
| 首次启动要"卡" 0.5~6 秒 | 扫描 `Weixin.exe` 内存取密钥（只读，一次性） | 不危险 |
| Windows 弹出"允许程序访问微信进程"之类提示/UAC | `OpenProcess` 权限需求 | 仅本地权限，不危险 |
| 杀毒报"读取其他进程内存" | 取证类工具常见误报 | 本工具只读不写；可自行审计 `wx4/image_key.py`、`wx4/_refdb.py` |
| 微信提示"当前设备环境异常" | 与本工具无关（通常是多开/换设备/代理导致） | 与本工具无关 |

## 4. 你的数据在哪、怎么清理

| 路径 | 内容 | 建议 |
| --- | --- | --- |
| `WechatMoments/.wx4_cache/keys/<账号>.json` | **数据库密钥（敏感！）** | 不要外传；退出前可删，删了下次重新取 |
| `WechatMoments/.wx4_cache/*.sqlite` | 解密出来的数据库快照（含聊天/联系人/朋友圈数据） | 含隐私，勿上传；`clear_cache()` 或直接删目录 |
| `WechatMoments/.wx4_cache/{img,avatar}/`、`image_key.json` | 解密图片、头像、图片密钥 | 同上 |
| `WechatMoments/output/朋友圈_*/` | 导出的 HTML + 图片（隐私内容） | 自己保管，别发群/网盘 |

清理：关闭程序后直接删除 `WechatMoments/.wx4_cache` 与 `WechatMoments/output` 即可，不影响微信本身。

## 5. 代码自检入口（想确认"没有偷偷干坏事"可以看这里）

- 只读内存：`wx4/image_key.py`、`wx4/_refdb.py`（只有 `OpenProcess/ReadProcessMemory/VirtualQueryEx`，
  没有 `WriteProcessMemory`/`CreateRemoteThread`/`SetWindowsHookEx`）
- 不写微信目录：`wx4/db.py`、`wx4/media.py`、`wx4/keycache.py` 的所有写操作目标都在 `WechatMoments/.wx4_cache/`
- 不模拟点击：`gui/gui.py` 顶部 `AUTO_BROWSE_ENABLED = False` + 两个自动浏览入口已禁用
- 不联网：`exporter/image_exporter.py` 已改为只用本地缓存（原版 3.x 是直接下载腾讯图片链接）

## 6. 合规边界

本工具仅用于导出**你自己有权查看**的朋友圈数据（备份自己的记录）。禁止用于窃取他人隐私、
未授权取证或其他非法用途。使用产生的任何法律责任由使用者自行承担。

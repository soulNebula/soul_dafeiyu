# 真实数据接入与学习流程

> 目标：新数据进来 → 清洗 → claim/画像 → 反馈 → 隔天验收。
> 不恢复旧客户数据；旧数据接入需单独明确授权。

## 一、数据从哪来

### 1. 801 微信（推荐，自动）

```text
白名单联系人 → 801 接收 → 每联系人独立 DB
→ selflearn 生成 → wxauto 回复 → 用户发「反馈 好/一般/差」
```

联系人库位置：

```text
agi/data/selflearn/wechat_contacts/<hash>.sqlite3
```

反馈入口：

```text
反馈 好
反馈 一般
反馈 差
```

### 2. 网页 8082

```text
http://127.0.0.1:8082/
```

每条回复下有 good/ok/bad 按钮，这是 explicit feedback。

### 3. JSONL 导入（可选，不默认）

```bash
python -m agi.selflearn.cli --db <db> ingest-jsonl --file data.jsonl
python -m agi.selflearn.cli --db <db> sessions
python -m agi.selflearn.cli --db <db> segment --session <id>
```

只接受新产生的、有授权的数据；旧客户数据需单独授权。

## 二、每天跑什么

```bash
# 1. 夜间整理：摘要/画像/反思/弱验证 + session 重建
python -m agi.selflearn.cli --db <db> nightly

# 2. 提案自动灰度（只 draft→gray，merged 人工）
python -m agi.selflearn.cli --db <db> proposal-auto-gray
python -m agi.selflearn.cli --db <db> proposal-weekly

# 3. 质量审计
python -m agi.selflearn.cli --db <db> quality

# 4. 生产门槛
python -m agi.selflearn.cli --db <db> production
python -m agi.selflearn.cli production-contacts
```

## 三、数据要喂到什么程度

### 801 联系人 production 门槛

```text
messages ≥30
turns ≥10
feedback ≥3
explicit_feedback ≥3
memories ≥5
persona ≥3
claims ≥5
active_days ≥3
feedback_days ≥2
```

当前 801 联系人库：

```text

memories 7 / persona 6 / claims 17
active_days 1
feedback_days 1
```

只差跨天。

## 四、哪些必须靠真实数据

| 能力 | 为什么 |
|---|---|
| S9 画像 10 维 | 需要真实工作/城市/家庭/健康等证据 |
| 13 黄金集/校准 | 需要人工标注 50–100 条 |
| 04 分数/情境桶 | 每桶需要真实反馈样本 |
| 09/10 情绪/信任 | 需要真实互动结果，不是规则能编 |
| production | active_days/feedback_days 只能真实跨天 |


## 四、冲突表（明确以谁为准）

| 项 | 我的 16 | wx_box 实测 | 采用 |
|---|---|---|---|
| 硬件 | 4060 8GB / 1.7B | 4050 6GB / **2B 训、4B 跑** | **wx_box** |
| 训练精度 | QLoRA 4bit | **2B bf16 LoRA**，QLoRA 不建议 | **wx_box** |
| 延迟目标 | P50 ≤2.0s | 现状 6.0s；目标「不高于现状 +10%」，先关 thinking | **wx_box** |
| 黄金集 | 手写 120 条 | 50 条起，来自真实场景 | 折中：**先 50，W4 补到 100** |
| 消融臂 | 4 条件 A/B/C/D | 3 臂：无 / 规则 / 小模型 | **4 臂**（补「静态人格」作对照） |
| LoRA 时机 | 3–6 个月 | 6–8 周后第一次 | **以数据为准，6–8 周为最早** |

> 我建议的 4 臂：**A 无状态 / B 静态人格 prompt / C 规则状态 / D 小模型状态**。
> 它比 wx_box 的 3 臂多一个 B——用来回答「是不是只要有一段人格描述就够了」，这个问题不回答，小模型的价值就永远说不清。

## 五、合并后的 6 周路线（wx_box 宿主）

| 周 | 做什么 | 交付/验收 | Kill 标准 |
|---|---|---|---|
| **W1** | 修 P0；黄金集 50 条；feedback 对账；基线 | 6 个回归测试 + `pytest` 全绿；50 条可复现黄金集；`turn↔feedback` 一致率 100%；基线延迟/质量可复现 | 周末仍无可复现评分 → 暂停 |
| **W2** | `inner_state` + 注入 + 四臂盲评（**不训练**） | 状态冲突率 <5%；延迟增量 ≤10%；四臂胜率 + CI | 小模型臂不赢规则臂 → 砍 inner，回规则状态机 |
| **W3** | pairwise + 隐式信号 | 每周 ≥20 对有效偏好；重复一致率 ≥70% | 一周 <40 对 → 交互设计失败 |
| **W4** | 数据集 + 离线评测工具 | 训练可复现；样本身份断言（turn/inner/feedback 齐全、无重复、时间切分正确） | 对账 <100% → 不导出 |
| **W5–6** | 2B LoRA smoke + 对照（shadow，不上线） | 离线 win rate ≥55%（CI 下界 >50%）；通用回退 <3%；P95 不升 | 任一不达标 → 回滚，路线降级为「prompt + 记忆 + 状态机」 |

**每周固定**：周日 30 分钟成长仪式（16 §10）——看 growth_log、top/bottom 10、3 条提案、灰度合并。

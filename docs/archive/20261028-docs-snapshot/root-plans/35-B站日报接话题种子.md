# 35 B站日报接入主动消息话题种子（P10）

## 数据来源

「刷B站」插件把日报写到：

```
C:\Users\Administrator\.dsh\bili-duty\out\<YYYY-MM-DD>.md
```

- `agi/integrations/bili_digest.py` 只读扫描，不写、不联网；
- 测试/换机用 `BILI_DUTY_OUT_DIR` 指向临时目录；
- `python -m agi.integrations.bili_digest --show` 可查看最新解析结果。

## 日报格式与解析

正常日报每个视频段落以：

```
### BV1xxxxxxxxx
标题（可写在下一行）
为什么值得：……
它自己的一句话：……
```

解析规则：
- 以 `### BV号` 分段，到下一个 `###`/`##` 或文末；
- 标题取 `###` 后同行文字，没有则取下一行（跳过「为什么值得 / 它自己的一句话 / > / 代码块」）；
- `why` 取「为什么值得」首句；没有则取正文第一句；
- `quote` 取「它自己的一句话」首句；
- 失败报告（含「没跑起来 / 退出码 / 没注册驱动 / NO_ADAPTER」且无 `### BV`）→ `[]`；
- 空文本、坏行、编码错误 → `[]`，不抛异常。

`latest_topics(days=2, limit=3)`：按 mtime 取近 N 天 `.md`，最新在前，BV 去重；
返回 `{topics, report_path, report_date, reports}`；失败报告也会给出最新
`report_date` 但 `topics=[]`。

## 接入 topic_seed

- 候选顺序：user_memories → claims → 24–72h 用户消息 → **B站日报**；
- B站最多 2 条，标题用 `clean_title()`：去【】/（）推广词、截断 30 字；
- `why` 不放入正文，只作为候选的 `direction`（可聊方向）；
- 标签：「最近刷到一条视频」；prompt 注入行：
  ```
  - 最近刷到「…」（视频，可聊）
  ```
- 仍保持「最多提 1 个、不复述记忆原文」；
- 过滤沿用 topic_seed：敏感/物理起居/最近 7 天主动消息 2-gram ≥3 重复；
- tick 返回 `topic_seed.sources = {bili: true/false, report_date: ...}`；
  worker `proactive_send` 日志带整个 `topic_seed`。

## 开关

| 开关 | 默认 | 关闭效果 |
| --- | --- | --- |
| `proactive_topic_bili` | true | 不读日报、不注入 bili 行；prompt 与原基线逐字节一致 |
| 环境变量 `PROACTIVE_TOPIC_BILI` | — | 0/false/off 可覆盖 |

连 `proactive_topic_seed=false` 时整个话题种子关闭，bili 自然也不注入。

## 失败报告处理

当前真实日报（2026-10-26/27）是「模型提供方没注册驱动 qianwen」的失败占位报告，
`parse_report` 返回 `[]`、`latest_topics` 返回 `topics=[]` + `report_date`，
因此不会把失败日志/日志尾部当话题注入主动消息。

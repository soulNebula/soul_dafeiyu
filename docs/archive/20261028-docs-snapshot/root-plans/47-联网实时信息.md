# 47 · 小鱼联网实时信息（P24，收尾版）

用户要求：给小鱼接**实时信息**，把"实时信息拿不到，别编"改成"能查就查，查到才说，查不到就说查不到"。

**最终范围（按用户 2026-10-27 调整）**：
- **不做**股价/指数/汇率/黄金/比特币（无对应代码）；
- **公众号先搁置**（微信 IP 级风控，本机直连 302 到 `wappoc_appmsgcaptcha`，
  r.jina.ai / allorigins / codetabs 代理均失败；代码保留但不作为主路径，出路见 §7）；
- **主攻普通网页搜索**：`search()` 搜狗→必应→必应中文、去重、域名；`fetch_url()`
  正文提取启发式；chat 搜到就注入 2–3 条摘要 + 1 个来源域名。

---

## 1. 触发规则（规则触发，不让模型决定）

`agi/integrations/web_lookup.py::detect_intent(text)` → `None` 或
`{kind, query, params}`。按顺序匹配：

| kind | 触发词/条件 | 查询函数 | 状态 |
| --- | --- | --- | --- |
| `wechat_article` | 文本里有 `mp.weixin.qq.com` 链接 | `wechat_article(url)` | 保留（blocked 提示） |
| `wechat_search` / `wechat_title` | 公众号/公众号文章/转发卡片标题/「链接」提示 | `wechat_search(q)` | 保留（不作主路径） |
| `url` | 其它 http(s) 链接 | `fetch_url(url)` | 主路径 |
| `weather` | 天气/气温/下雨/冷不冷/热不热/穿什么/预报（提取城市，否则默认/IP） | `weather(city)` | 主路径 |
| `news` | 新闻/最近发生/今天有什么/热搜/热点/大事（`NEWS_ENABLED=false` 不触发） | `news(topic)` | 主路径（top3） |
| `search` | 查一下/搜一下/帮我查/百度一下 + 关键词 | `search(q)` | **主路径** |

明确**不触发**：股价/指数/汇率/美元/黄金/比特币；普通闲聊、情绪表达、问时间
（时间由 P16-A 上下文解决）不触发。

## 2. 普通网页搜索（主路径）

`search(query, limit=5)`：

- provider 顺序：**搜狗 → 必应 → 必应中文**（`cn.bing.com`），失败/结果不足自动切换，
  非空结果合并后再去重；
- 解析：标题 + 摘要 + URL + **域名**；`_clean_search_query` 去掉
  「请问/什么是/帮我查一下/是什么/怎么」等口头前缀与尾巴，避免搜索引擎只命中第一个词
  （实测「什么是光合作用」→ 查询「光合作用」后结果才相关）；
- **去重**：URL 归一化去重 + **同域名最多 2 条**，再取前 `limit` 条；
- 返回 `{ok, items:[{title,url,summary,domain}], count, source:"搜狗+必应", query, error}`；
- 失败 `ok:false + error`，不编造。

真实 smoke（2026-10-27，本机联网）：

| 查询 | 耗时 | 结果相关性 |
| --- | --- | --- |
| 「什么是光合作用」 | **954 ms**（必应） | 百度百科/知乎/高中生物，全部命中「光合作用」 |
| 「Python 3.14 新特性」 | **836 ms**（必应） | 知乎/阿里云/官方文档，命中 3.14 新特性 |
| 「人工智能 最新消息」 | **1457 ms**（必应） | AI 日报/OpenAI 动态/7 月精选等时效聚合页 |
| chat「帮我查一下光合作用是什么」 | **2206 ms** | 注入 3 条摘要 + 来源 baike.baidu.com，模型回「搜了下，光合作用就是…」 |

## 3. fetch_url 正文提取（主路径）

- 仅 http(s)，**SSRF 防护**：localhost / 127/8 / 10/8 / 172.16/12 / 192.168/16 /
  169.254 / ::1 / 0.0.0.0 / 解析到内网的域名一律拒绝；≤300KB；正文前 3000 字。
- 正文密度启发式：去 script/style/iframe/form/nav/footer/header/aside 等噪声标签，
  去 class/id 含 nav/menu/sidebar/advert/comment/share/cookie/related 等的容器；
  在 `article` / `main` / `[role=main]` / `.post-content` / `.article-content` /
  `#content` / `.content` / `body` 中选**段落文本最多**的容器；清理版权行/UI 噪声行
  （浅色/深色/主题色/登录/分享/收藏等），并从标题行开始截取。
- 返回 `{ok,title,text,url,size,truncated,domain,source,error}`。
- 实测：IT之家文章 **99 ms**，23KB，提取文本从标题开始、无站点导航/广告/版权行，
  正文段落干净。

## 4. 天气 / 公众号 / 新闻

| 能力 | 数据源 | 说明 |
| --- | --- | --- |
| `weather(city)` | wttr.in `format=j1`（无 key；IP 定位）→ 失败腾讯天气 | temp/desc/feels/humidity/wind/city；摘要中文（北京现在晴，12℃…）；实测 1.8s |
| `wechat_article(url)` | `mp.weixin.qq.com` | 保留：解析标题/公众号/时间/正文（≤4000 字），反爬验证页 `blocked` + 中文出路提示；**当前网络直连被 302 到 captcha，搁置** |
| `wechat_search(q)` | 搜狗微信 top5 | 保留：标题/公众号/摘要；验证码 → 友好失败；实测可用（459ms / 5 篇真实文章） |
| `news(topic)` | RSS：IT之家/中国新闻网/少数派/36氪/新浪 → 搜狗新闻 | **top3**；RSS 有日期且全部 >3 天自动退搜狗；实测 148ms 当天新闻 |

## 5. chat 接入

`agi/selflearn/chat.py::send()` 生成前：

1. `web_lookup.enabled()` 才查询（`WEB_LOOKUP_ENABLED`，默认 true）；
2. `detect_intent(text)` 命中 → `lookup(text)`；
3. `ok=True` 且有 summary → 压成 ≤400 字"实时资料"块，放在 `user_text` 之前：
   `实时资料（刚联网查到，只能依据它回答；资料里没有的就说查不到，别编）：…`
   - **搜索**：2–3 条标题+摘要 + **最多 1 个来源域名**；额外提示"回答可以自然说
     「搜了下，…」；不要贴长链接列表，最多提一个来源域名"；
   - 公众号文章：`这篇我看完了…可给一句自己看法，别长篇转述`（保留）；
   - 转发标题：`只检索到摘要、没读到全文：可以聊大意，别说看了全文`（保留）；
   - 公众号 blocked：**即使 ok=False 也注入**"这篇被微信拦了（反爬验证），你把正文
     复制发我就行。如实告诉用户，别假装读过"。
4. **查不到/网络失败 → 不注入**，prompt 与未命中逐字节一致（测试锁定）；
5. 结果 dict 加 `web_lookup:{kind,ok,source,error,title,hint}`；
   trace 的 `generation_json.web_lookup` 可见；
6. SYSTEM 文案：「实时天气/新闻/公众号文章/网页信息能联网查：能查就查，查到才说，
   查不到就说查不到，别编」。不改 prompt_store/生成/守卫/润色顺序。

## 7. 公众号：搁置原因与出路

**原因（2026-10-27 实测）**：直接 requests 抓 `mp.weixin.qq.com/s?...` 一律 302 到
`https://mp.weixin.qq.com/mp/wappoc_appmsgcaptcha?poc_token=…&target_url=…`，
PC/微信移动 UA、Referer 均无效；r.jina.ai / allorigins / codetabs 代理全部失败；
搜狗文章跳转也进 antispider。微信按 IP 风控，服务端抓全文这条路走不通。

**保留的能力**（不作主路径）：
- `wechat_article`：blocked 时给中文出路提示 + `hint`；chat 注入提示让模型如实说
  "这篇被微信拦了，你把正文复制发我就行"，不假装读过；
- `wechat_search`：搜狗微信 top5（实测可用），用户搜公众号文章时可用；
- 转发标题兜底（`wechat_title`）：只抓检索摘要 top1-2，注明"只看到检索摘要，没读到全文"；
- 全文升级钩子：`wechat_article(url, fallback_text=...)`，为后续"用户粘贴正文 /
  PC 微信读窗口 / 登录态抓取"预留（已测试，不联网优先）。

**出路**：用户把正文复制发给小鱼；或后续做 PC 微信登录态/窗口读取；不为此增加代理依赖。

# 本地模型安装（Phase 2）

> 目标：没有 GPU 也能云端跑；有 GPU 时再装 llama.cpp + GGUF，按 Bot 启停本地模型。
> 所有模型文件放 `AGENT_HOME`（默认 `E:\agent`），不随仓库分发。

最后更新：2026-10-30

## 1. 先检测硬件

803 → Bot 页 →「本机硬件 / 方案推荐」→ 检测。

- 无 GPU：只走云端（按决策）
- 6GB 以下：不建议本地训练
- 6–8GB：0.5B + 3B 推理
- 8–12GB：可跑 7B 量化
- 12GB+：可跑 14B/多模型

## 2. 安装 llama.cpp

```powershell
# 只检查
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_llama.ps1 -CheckOnly

# CUDA 版（有 NVIDIA GPU）
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_llama.ps1

# CPU 版（无 GPU，慢）
powershell ... -File .\tools\setup_llama.ps1 -CpuFallback
```

- 安装到 `<AGENT_HOME>\llama\cuda\llama-server.exe`
- 默认拉 GitHub llama.cpp release；国内慢时用：
  ```powershell
  ... -AssetUrl <llama-win-cuda.zip 直链> -CudartUrl <cudart.zip 直链>
  ```
- 不会自动下载 GGUF，也不会自动启动模型。

## 3. 下载 GGUF（断点续传 + 校验）

```bat
python tools\fetch_model.py --url https://.../model.gguf ^
  --out E:\agent\models\my-soul\model.gguf --sha256 <64位sha256>
```

- 先写 `.part`，中断重跑会 Range 续传
- 校验失败保留 `.part`，不会覆盖目标文件
- 也可以直接在 803「模型中心」用直链/HuggingFace 下载

## 4. 启动本地模型

用 802 模型页启动（推荐）：

1. 802 →「模型」→ 刷新
2. 找到 `soul-05b` / `qwen25-vl-3b` / 训练导出的 soul 模型
3. 点「启动」
4. 端口在注册表里（8123/8125/8126+）

或命令行：

```bat
E:\agent\llama\cuda\llama-server.exe -m E:\agent\models\xxx.gguf ^
  --host 127.0.0.1 --port 8125 -c 8192 -ngl 99 --jinja
```

## 5. 按 Bot 隔离

- `local_models.json` / `local_models_state.json` 已按 Bot 数据根解析
- 切 Bot 后模型注册表、启停状态不串
- 训练导出的模型会自动注册到当前 Bot，并尝试自动启动/切换（`SOULAGENT_AUTO_START_TRAINED=0` 可关）

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 无 GPU 但想跑 | `-CpuFallback`，速度慢很多，不建议训练 |
| 下载 GitHub 失败 | 用镜像直链 `-AssetUrl/-CudartUrl`，或 803 模型中心直链 |
| `llama-server.exe` 起不来 | 检查 CUDA/cudart DLL 是否在同目录；`-CheckOnly` 看路径 |
| 显存不足 | 降 `-ngl` / 换 Q4 / 减小 `-c` |
| 802 模型页看不到新模型 | 803 导出后自动注册；若没有，检查 `local_models.json` 与 Bot 数据根 |

# 桌面版（Windows / M5）

> 把 801 网关、802 控制台、803 工作台包成一个「双击即用」的桌面入口：
> 启动服务 → 托盘常驻 → Edge app 独立窗口。当前只做 Windows。

最后更新：2026-10-29

## 1. 入口

| 入口 | 说明 |
| --- | --- |
| 桌面快捷方式 **「小鱼桌面版」** | `pythonw.exe tools\desktop\launcher.py --tray`，**无控制台窗口**，推荐日常使用 |
| `启动桌面版.bat` | 等价入口（有控制台，便于看启动日志/传参） |
| 命令行 | `python tools\desktop\launcher.py [--tray] [--no-open] ...` |

**不要用「以管理员身份运行」**：管理员启动会把提权传给 Edge，触发
「现有实例正在以提升的权限运行」弹窗；启动器检测到管理员时，会自动改用普通权限浏览器打开。

## 2. 启动时做什么

1. 探测 801 / 802 / 803：
   - 没跑 → 后台起进程（不弹控制台；803 用 `idea/.venv`、cwd=`idea/`）；
   - 已在跑 → 复用，不重复启动；
2. 等健康检查通过（`/health`、`/api/health`、`/api/wb/health`）；
3. 用 Edge/Chrome `--app` 模式打开 802 控制台（1440×900）；没有浏览器时回落默认浏览器；
4. `--tray` 时拉起系统托盘（`tools/desktop/tray.ps1`，单实例）。

启动日志：`E:\agent\logs\desktop_*.log`（不可写时回落 `agi\data\desktop_logs\`）。

## 3. 参数

| 参数 | 作用 |
| --- | --- |
| `--tray` | 系统托盘：打开控制台 / **打开工作台** / 主动消息开关 / STOP / 状态 / 日志 / 退出 |
| `--open-workbench` | 打开 803 工作台窗口（默认打开 802） |
| `--no-open` | 只保证服务在跑，不开窗口 |
| `--persist`（默认） | 关窗口后服务保留 |
| `--exit-with-window` | 关窗口后停掉**本启动器拉起的**服务 |
| `--status` | 打印 JSON 状态（含各服务 PID / 窗口 / 托盘） |
| `--stop` | 停掉本启动器拉起的服务 |
| `--autostart install/uninstall/status` | 开机自启（写「启动」目录 bat；加 `--autostart-registry` 写 HKCU Run） |
| `--log-dir` / `--state-path` / `--profile-dir` | 自定义日志/状态/浏览器 profile（测试用） |

## 4. 排障

| 现象 | 原因与处理 |
| --- | --- |
| 弹「Microsoft Edge 未响应：现有实例正在以提升的权限运行」 | 你用了管理员启动；关掉弹窗，**普通双击**快捷方式即可。启动器已内置管理员回落 |
| 一闪而过的黑窗/管理员 PowerShell | 旧版启动器用 PowerShell 查询窗口状态导致；2026-10-29 已改为隐藏执行 + Win32 API 读标题，不再闪窗 |
| 窗口打开但空白灰底 | 启动器会检测窗口标题（应含 `Soul Console`）；空白/残留窗会被关掉重开，仍失败则回落默认浏览器 |
| 首次打开很慢（20–30s） | Edge 首次使用独立 profile 冷启动，正常；之后复用窗口秒开 |
| 托盘图标没出现 | 托盘是 PowerShell + WinForms，被安全软件拦截时看 `desktop_tray.log`；可先只用窗口 |
| PyInstaller exe 打不开（0xc0000142） | 本机安全软件/加载器拦截；已不推荐 exe，用 pythonw 快捷方式。`build_exe.ps1` 保留，换机器可再试 |

## 5. 与 M5 的关系

- M5 桌面化（Windows）已落地：托盘 + 独立窗口 + 三服务托管 + 自启 + 状态/停止；
- 非 Windows 平台未适配（UIA/微信/Edge app 参数均 Windows-only）；
- 桌面壳是「Edge app 窗口 + 托盘」，不是 Tauri/WebView2 自绘窗口；如需更原生的壳再单独立项。

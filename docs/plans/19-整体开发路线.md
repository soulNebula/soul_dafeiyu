## 三、目标架构（v1）

```
微信 ←→ wx_core（只读采集）
              │
        agi/wechat_gateway（801，收/发/策略）
              │
        agi/selflearn/chat.py  ←── 唯一主链，只改 2 处
              │  ① _prompt() 注入 <inner_state>（≤120 字）
              │  ② turn 落库加 inner_id / prompt_hash / model_version
              ▼
        agi/inner/  （新建，4 个文件）
          schema.py    InnerState + JSON schema + 校验
          render.py    状态卡（规则，零延迟）+ 模板兜底
          inject.py    build_block() + sanitize()
          store.py     inner_state 追加表
              │
        DeepSeek（大模型）→ guard → 发送策略
              │
        反馈（good/ok/bad + pairwise + 隐式）→ 数据集 → 评测 → （W5）LoRA
```

**关键决定：v1 只新建 `agi/inner/`，不建全量 `agi/hybrid/`。**
`hybrid/` 的 router/dataset/finetune/evaluate 等，等 W4–W5 真需要时再按需建，避免为一个状态注入引入 10 个空文件。

### P1 · W2：内状态 + 四臂盲评（8h，不训练）

| 任务 | 文件 | 验收 |
|---|---|---|
| 建 `agi/inner/` 四件套 | 新包 | 单测通过；关掉开关行为不变 |
| 扩展 `state.py` 的 `self` 子结构（不新起一套） | `state.py` | 状态可回放；衰减正确 |
| 注入 `<inner_state>` | `chat.py:_prompt()` | 增量 ≤120 字；不进证据段 |
| 四臂开关 `INNER_MODE=off|static|rule|model` | `chat.py` / `inner/` | 同一会话可切 |
| 跑四臂盲评 | `agi/data/eval/ablation_w2.md` | 100 context × 4；胜率 + Wilson CI |

**四臂**：A 无状态 / B 静态人格 prompt / C 规则状态 / D 小模型状态（W2 先用 DeepSeek 扮演 D，本地 2B 在 W5 接）。
**判据**：D vs C 显著 > C？C vs A 显著？延迟增量 ≤10%（现状 6s）。
**Kill**：D 不赢 C → 砍 model 臂，保留规则状态；C 不赢 A → 整个 inner 方向停。

### P2 · W3：偏好与隐式信号（6h）

| 任务 | 文件 | 验收 |
|---|---|---|
| `/api/pairwise` + 控制台双版盲选 | `web.py` | 每周 ≥20 对有效偏好 |
| 隐式信号扩展 | `implicit_feedback.py` | **只加权，不做标签** |
| 负例池 | `feedback` | bad/纠正 ≥30 条；不到不训 |

**Kill**：一周 <40 对 → 交互设计失败，重做入口。

### P3 · W4：数据集 + 离线评测（8h）

| 任务 | 文件 | 验收 |
|---|---|---|
| `dataset.py` | `agi/inner/` | join turns × inner × feedback；**按时间切分**；身份断言 |
| `evaluate.py` | `agi/inner/` | 黄金集 + 盲评 + 回归 + 延迟，可一键跑 |
| 导出 | `agi/data/datasets/` | ≥500 条 train/val，无同会话泄漏 |

**Kill**：对账 <100% → 不导出。

### P4 · W5–6：2B LoRA shadow（12h）

| 任务 | 配置 |
|---|---|
| 训练 | Qwen3.5-2B + bf16 LoRA（Unsloth，py312）；r=16、lr 1e-4、2–3 epoch、seq 1024；**从 base 重训**；混 10–30% 通用数据；20% 验证 |
| 部署 | 导出 GGUF → Ollama；`INNER_MODEL=local` 一键切回 |
| 对照 | 有/无 adapter 双盲，shadow 只记录不发送 |

**上线门槛（全过）**：胜率 ≥55% 且 CI 下界 >50%；安全回归 0；通用回退 <3%；P95 不升。
**Kill**：任一不达标 → 回滚，路线降级为「prompt + 记忆 + 状态机」，不再训。

### P5 · W7+：常态化

- 每周日 30 分钟成长仪式（16 §10）：top/bottom 10 → 3 条提案 → 灰度 → changelog；
- 2–4 周一个 adapter（不是每周）；
- 每季度黄金集轮换 30%；
- 只在白名单联系人上灰度，随时可切回纯大模型。

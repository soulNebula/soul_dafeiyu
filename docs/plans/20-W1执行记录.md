## 二、两个 P0 的根因（写给未来的自己）

### P0-1 危机分支崩溃

- `chat.py` 危机分支只设置 `reply`，跳过 `generation.generate`，而返回体引用 `gen_meta`；
- 于是 `UnboundLocalError: gen_meta`，消息与 turn 已落库，但 Web/微信拿不到结果 → **危机用户收不到任何回复**；
- 修复：危机分支前初始化 `gen_meta = {"two_stage": False, "claims": []}`；不改分支逻辑。

### P0-2 三级分享失效

- `proactive.py` 顶部 `from . import ... sharing ...`；
- `tick()` 内 `sharing = float(...)` 遮蔽模块，`sharing.choose_level()` 抛 `AttributeError`，被 `except Exception: pass` 吞掉；
- 结果 `share_info` 恒 `{}`，`share_candidates.level` 177 行全空；
- 修复：局部变量改名 `share_drive`（6 处），模块调用不动；
- 遗留：那个静默 `except` 仍在，同类问题还会被藏住 → 建议后续加日志或 CI pyflakes。

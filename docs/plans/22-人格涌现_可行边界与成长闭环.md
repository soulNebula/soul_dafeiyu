# 22 · 人格能否「自己涌现」：可行边界与成长闭环

> 问题：能不能通过持续聊天 + 自学习/半监督/无监督学习，让人格和性格**自己长出来**？需要多大时间成本？
> 结论先行：**「人格稳定地长出来」可以工程化，约 6–12 个月；「自己涌现出学习能力」不能按项目排期，属于研究命题，不建议承诺。**

---

## 一、先拆三个「学习」，否则会一直混在一起

| 层 | 机制 | 现在有没有 | 能不能让人格长出来 |
|---|---|---|---|
| **上下文学习** | 把记忆/关系/状态放进 prompt | ✅ 已有 | 能让人格**稳定**，但不会自己变 |
| **权重学习** | LoRA/蒸馏/偏好优化 | ✅ 可做（W4） | 能改**口吻/状态判断**，不产生新人格 |
| **自 directed 学习** | 自己定目标、自己找数据、自己验证、自己改自己 | ❌ 没有可靠方法 | **这才是「涌现」所指，但没有工程路径** |

你说的「涌现出来了就说明它拥有学习能力」其实反了：**学习能力是前提，不是结果**。
模型现在就会「在上下文里学」；它缺的是**自己设定目标 + 自己验证 + 自己改自己**，这在当前规模没有可复现的方法。

---

## 二、为什么「无监督自学习」会退化（已有明确证据）

1. **模型坍缩（model collapse）**：用自己生成的数据反复训练，分布会收窄，最后只会说少数几种话。
2. **自我蒸馏收敛**：学生模仿老师，几轮后信息量趋零——越训越像模板，不是越训越像人。
3. **奖励黑客**：用「用户继续聊」当正样本，会训出话痨/讨好型（QQ 落地包 05 §零 已经把这条写死）。
4. **漂移不可审计**：权重里的变化查不到、删不掉、回滚只能整包退。

00 文档 §2 的原话就是：**「无监督自我进化 → 会退化成自恋 + 幻觉自我强化。」** 这不是保守，是已经踩过的坑。

---

## 三、那「人格长出来」到底靠什么

不是靠「让模型自己训自己」，而是靠**选择压力 + 记忆 + 周期固化**：

```
每天聊天
  → 记忆/关系/状态（外部，可查可删）
  → 每周盲评 + pairwise（选择压力：什么被保留）
  → 每月把「被选中的行为」蒸馏进 adapter（固化）
  → 版本化 + 回滚 + 漂移上限（不失控）
  → 回到每天聊天
```

**人格 = 你的反馈在几个月里筛出来的稳定分布**，不是模型自己悟出来的。
「意外时刻」更可能来自**记忆 × 情境 × 状态**的组合，而不是权重突变——W2 的实验已经说明了这一点。

---

## 四、时间与成本（诚实版）

| 项 | 估算 |
|---|---|
| 人的时间 | **2–4 小时/周**（聊天、标注、看评测），一年 **100–200 小时** |
| 现金 | API ¥30–100/月；电费/云 GPU 几乎可忽略；一年 **¥500–1500** |
| 算力 | 2B LoRA 30–60 分钟/月，6GB 本地可跑 |
| 达到「稳定人格」 | **约 3 个月**：口吻稳定、记得住、前后一致 |
| 达到「可辨认的独特人格」 | **约 6 个月**：盲评能认出「这是它」 |
| 达到「你自己觉得它长出来了」 | **9–12 个月**，且取决于你投入的质量 |
| 达到「自主涌现学习能力」 | **无法排期**；研究级，1–3 年全职也未必有 |

**瓶颈不是钱、不是显卡，是你的注意力。** 每周 2–4 小时、连续半年，才是真正的成本。

---

## 五、把「成长」变成可测的指标（否则只是感觉）

| 指标 | 怎么测 | 目标 |
|---|---|---|
| 人格一致性 | 20 题隔 7 天问两次，立场一致率 | ≥85% |
| 可辨认度 | 盲评：3 条回复里挑出「它」 | ≥70% |
| 关系深度 | 主动引用共同记忆的比例 | 逐月上升 |
| 漂移指数 | 每周黄金集分数波动 | <0.3 |
| 新颖度 | distinct-2 / 新表达比例 | 不持续下降 |
| 成长日志 | 每周改了什么、依据哪几轮 | 100% 可追溯 |

**没有这六个数字，「长出来了」只是最近一次惊艳回复的错觉。**

## 六、里程碑（如果真要走这条路）

| 阶段 | 时间 | 交付 | 判据 |
|---|---|---|---|
| M1 稳定 | 0–3 月 | 记忆/关系/口吻稳定；周报 | 一致性 ≥85%、纠错复发 0 |
| M2 可辨 | 3–6 月 | 月度 adapter + 盲评 | 可辨认度 ≥70%、漂移 <0.3 |
| M3 成长 | 6–12 月 | 成长日志 + 季度复盘 | 盲评趋势向上、你自己能说出「它变了什么」 |
| M4 涌现？ | 12 月+ | 不承诺 | 如果出现，是发现，不是交付 |

---

## 七、三条红线（别越）

1. **不做无监督自训**：训练数据必须混真实数据 + 外部选择信号 + replay，否则必坍缩。
2. **不宣称「自主进化」**：对外只说「按你的反馈在变」，这是可解释的。
3. **不删人工审核**：core 人格、安全边界、上线门禁，永远有人。

---

## 八、和当前 W4 的关系

- **W4（2B 蒸馏）**：解决「嗓音/状态判断」的小型化与私有化，是**固化**环节；
- **W3（pairwise/反馈/延迟）**：解决**选择压力**的采集；
- **成长闭环**：W3 采集 → 每周盲评 → 每月 W4 固化 → 记忆/状态继续累积。

**一句话：人格不是「训」出来的，是「选」出来的；模型只是把它说得更顺口。**

# 38 兴趣画像（P12-B）

> 刷视频范围 = ①用户聊天关键词 ②B站推荐 ③它自己长出来的兴趣。兴趣只存 topic，不存原句。

## 表（persona 库）

`interests`：id, topic(UNIQUE,规范化), weight, source(chat|video|self|recommend),
evidence_json, hits, last_seen_at, created_at, updated_at。

`interest_events`：id, topic, delta, reason(observe_new/observe_update/decay/rebuild),
source, ref_json, at（审计，可复盘）。

## 来源加权

| source | 来源 | 单次 delta（≤0.15） |
| --- | --- | --- |
| chat | 用户聊天里提到的 | 0.15 |
| video | 看完/高 value 视频的 topics | 0.09 |
| self | 它自己反思提出的新方向 | 0.06 |
| recommend | 推荐流里点开的 | 0.045 |

- 每次 observe 最多新增 5 个 topic；同 topic 单次增量 ≤0.15。
- 抽取优先 `agi.llm.chat("keyword_extract")`（本地 3B）；失败/坏 JSON 退回规则
  （中文 2–4 字 + ASCII 词 + 停用词表）。
- 归一：小写/去标点、同义词合并（AI/人工智能→ai，手冲→咖啡，LLM→大模型等）。

## 衰减

- `decay(path, now)`：`w = 0.1 + (w-0.1) * 0.5^(days/7)`；
- 半衰期 7 天；小步多次 == 大步一次（指数）；`hits` 不清零。

## 检索/自提

- `top_topics(limit)`：按 weight、last_seen 排序。
- `search_keywords(limit)`：weight × 近期衰减 × 未探索（hits 低）排序，供 B站搜索。
- `propose_new(limit=2)`：`chat("persona_reflect")`（API）基于现有画像生成 1–2 个
  新方向，写入 `source='self'`。
- `rebuild_from_history(days=30)`：先清后建（幂等）；从 `bili_impressions.topics_json`
  （video）+ 近 30 天 user_memories/messages（chat，本地 keyword_extract）重建。
- `next_search_keywords(limit, path)`：合并 search_keywords + propose_new，state 表
  24h 缓存。

## 接线

- `bili_ingest.ingest()` 成功后 `observe(topics, source="video", ref=bvid)`；
  开关 `BILI_FEED_INTERESTS` 默认 true；失败不影响摄取。
- `chat.send` 每 5 轮 `observe([user_text, reply], source="chat", ref=turn_id)`；
  try/except，失败不影响回复。

## CLI

```bash
python -m agi.selflearn.interests --show --limit 10
python -m agi.selflearn.interests --rebuild --days 30
python -m agi.selflearn.interests --propose
python -m agi.selflearn.interests --decay
```

均支持 `--path <base.sqlite3>`（测试/副本用）。

## 消费与隐私

- 后续刷 B站用 `next_search_keywords`；主动分享/人格沉淀用 top_topics。
- 隐私：库里只有 topic 和引用摘要，不存聊天原句；证据 JSON 只留来源标记（bvid/turn_id）。
- 兴趣是概率性倾向，不是事实；不应据此对用户下定论。

# 39 · 推理过程可视化（P15-A 后端采集）

用户要求：**在控制台看到整个模型的推理过程**——每条回复的上下文 / 记忆检索 / 内状态 /
心情判定 / 生成原文（含 reasoning）/ 润色 / 守卫 / 最终发送 / 耗时。

本任务只做**后端采集 + 查询 API**；前端页面在 task-93（w3-feedback），
接口契约见第 4 节。原则：**只读采集，失败绝不影响回复主链**。

## 1. 数据表（记忆库 `turn_traces`）

## 2. 采集模块 `agi/selflearn/trace.py`

```python
trace.record(path, payload)                     # 底层：归一化/截断/裁剪/落库，失败返回 None
trace.record_chat(path, turn_id=..., user_text=..., system_prompt=..., prompt_user=...,
                  memories=..., inner=..., mood=..., generation=..., polish=...,
                  guard=..., final_reply=..., skipped=..., skip_reason=..., crisis=...,
                  latency_ms=...)                # chat.send 便捷入口
trace.record_proactive(path, result, contact=..., extra=...)  # proactive.tick 便捷入口
trace.list_turns / get_turn / stats / stream    # 查询（trace_api 用）
trace.settings() / enabled()                    # 开关
```

### 截断与清理

- prompt 类字段（`system_prompt` / `prompt_user`）各 ≤ **20KB**（UTF-8 字节，保头 62% +
  尾 38%，中间插 `…（trace 已截断 N 字节）…`）；
- 其它文本/JSON 字段同样上限 20KB；
- **整条记录 ≤ 100KB**：超了从最大字段开始循环截断直到放得下（不会写超）；
- 表最多保留 `trace_max_rows`（默认 5000）条，超出按 `ts` 删最旧；
- 所有写入包 `try/except`：trace 故障**不影响回复主链**；
- proactive：只记「有决策内容」的 tick（available/kind/candidates/message），
  「刚聊过/还没对话」这类每 30s 的静默轮询不记，避免刷爆表。

### 开关（wechat config，默认开）

```json
{"trace_enabled": true, "trace_max_rows": 5000}
```

环境变量优先：`TRACE_ENABLED`、`TRACE_MAX_ROWS`；测试可用 `TRACE_CONFIG_PATH`
指向临时配置，`TRACE_DB_PATH` 覆盖默认库。

## 4. 查询 API（控制台，只读，admin token）

模块：`tools/console/trace_api.py::handle_trace(path, query)`。
`tools/console/server.py` 已接好 `GET /api/trace/*` → `trace_dispatch()` → 动态加载本模块：

```python
# server.py 里只此一处（w3-feedback 已加）：
result = trace_api.handle_trace(suffix, query)   # suffix="/turns" 等；query=parse_qs dict
```

| 路由 | 参数 | 返回 |
| --- | --- | --- |
| `GET /api/trace/turns` | `limit`(50) / `mode`(chat\|proactive) / `contact` / `db` | `{ok, items:[{id,ts,mode,contact,user_text(≤160),final_reply(≤160),latency_ms,skipped,skip_reason,crisis,kind}], turns 同义, count}` |
| `GET /api/trace/turn` | `id` / `contact` / `db` | `{ok, item:{...完整字段...}, turn 同义}`；JSON 字段解析为对象，另附 `raw` 原始字符串 |
| `GET /api/trace/stream` | `limit`(20) / `since`(ts) | `{ok, events:[摘要...], items 同义, count}`（前端轮询增量） |
| `GET /api/trace/stats` | `days`(7) | `{ok,total,avg_latency_ms,skip_rate,p95_latency_ms,p95,two_stage_rate,crisis_count,by_mode,by_day,stats}` |
| 未知路由 | — | `{ok:false,error:"not_found:<route>"}`（console 会用完整 path 重试一次） |
| 可选 token | `handle_trace(..., admin_token="x")` | `{ok:false,status:401,error:"admin token required"}` |

**数据库路径**：`db`/`db_path`（显式）> `TRACE_DB_PATH` env > `contact`（网关同款
alias→sha1 库）> 默认真实联系人库（最后兜底 selflearn DB）。
console 前端按当前选中联系人传 `contact=<alias>` 即可。

## 5. 隐私

`system_prompt` / `prompt_user` / `user_text` / 回复原文都**含用户真实对话内容**（P16-A 后 system prompt 还含当前时间行）；
`turn_traces` 只存在本机 `agi/data/selflearn/...` (sqlite)，接口只在 console 本机
admin token 后暴露（console 的 `token_ok` 先行校验）。不要把 trace 数据导出/上传；
控制台页面自己也要显示「仅本机」提示。默认 5000 条滚动保留，旧的自动删。

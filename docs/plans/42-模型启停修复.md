# 42 · 模型页启停修复（P20）

> 用户报障：模型页停止 soul-05b 弹英文 `not_started_by_registry`；启动弹两次且「PID ?」。
> 根因：8123 的 llama-server 是**命令行手动启动**，`local_models_state.json` 没有 PID；
> 旧 `stop()` 直接拒绝，旧 `start()` 只回 `already_running` 不带 PID。
> 本任务分两段：**① 注册表修复（已完成）**；**② 控制台 UI（等 w3-feedback 的 P17 落地后再改）**。

## 1. 注册表修复（`agi/selflearn/model_registry.py`，已完成）

### stop()

- 先看注册表 state：
  - 有记录且 PID 存活、端口 owner 一致、命令行安全 → kill 并清 state，返回
    `{ok:true, pid, port, external:false, hint:"已停止 ..."}`；
  - 记录失效/端口不符 → **只清脏记录，绝不 kill**，转外部进程识别。
- 无有效记录时按端口反查 PID（`_port_pid`，netstat）：
  - 端口未监听 → `{ok:false,status:"not_running",error:"not_started_by_registry",
    hint:"端口 8123 当前没有在监听..."}`；
  - 查不到 PID → `status:"pid_unknown"`，不 kill；
  - 命令行**必须同时含 `llama-server` 与 `.gguf`** 才认为安全，否则
    `status:"refused", error:"unsafe_process"`（中文 hint，不 kill）；
  - 安全的外部进程：默认返回
    `{ok:false, status:"external", external:true, needs_confirm:true, pid, port, hint}`
    （中文「停止前请二次确认」），**不 kill**；
  - 控制台二次确认后传 `force_external=true` → 再校验后 kill，返回
    `{ok:true, external:true, pid, port, hint}`。
- CLI：`--stop NAME [--force-external]`。

### start()

- 端口已在监听 → 不再只看 `health`，而是反查真实 PID：
  `{ok:true, already_running:true, pid:真实PID, port, external:bool, healthy, hint}`
  - `external=true` 表示不是注册表 state 里记录的进程（用户手动起的）；
  - 非 llama-server 进程占用端口 → `port_in_use_by_other_process`，不启动。
- 端口未监听 → 正常 spawn，返回 `{ok:true, pid:新PID, port, external:false, hint}`。
- 新增 `_port_open`、`_port_pid`、`_process_cmdline`（psutil 优先，PowerShell 回退）、
  `_process_identity`（llama-server + .gguf）、`_kill_pid`；`_pid_alive` 保留。

### 真实环境只读验证（未 kill）

```text
$ python -m agi.selflearn.model_registry --start soul-05b
{"ok":true,"already_running":true,"pid":26264,"port":8123,"external":true,
 "healthy":true,"hint":"端口 8123 已有 llama-server 在运行（PID 26264，外部启动），未重复启动。"}

$ python -m agi.selflearn.model_registry --stop soul-05b      # 不确认，不 kill
{"ok":false,"status":"external","external":true,"needs_confirm":true,
 "pid":26264,"port":8123,"hint":"检测到 soul-05b 是外部启动的 llama-server（PID 26264...）；停止前请二次确认..."}
```

## 2. 控制台改动（已完成）

`tools/console/server.py` / `app.js` 已在 P17 落盘后重读并只改模型相关区块，未覆盖素材库页：

1. **server.py**
   - `models_snapshot()` 增加 `running/pid/external`（来自 registry 新 `runtime_info()`），卡片据此显示外部徽标；
   - `stop_model(name, force_external=False)` 透传 `force_external`；`/api/models/stop` 读取 body 的 `force_external`；
   - 新增 `MODEL_ERROR_HINTS` + `_with_model_hint()`：`not_started_by_registry/external/unsafe_process/…` 统一转中文 hint；注册表已给中文 hint 时原样透传；
   - `start_model()` 返回原样 `pid/already_running/external/hint`，补中文 hint。
2. **app.js**
   - `api()` 非 2xx 时保留 `error.payload`，并优先用 `payload.hint` 作为 `e.message`；
   - 启动：`modelBusy` 防重复提交；toast 用真实 `result.pid`；`already_running` 显示「已在运行（外部启动，PID xxx）」；
   - 停止：先调普通 stop；若返回 `status=="external"/needs_confirm`，弹「soul-05b 不是控制台启动的（PID xxx、端口 8123），仍要停止吗？」；确认后带 `force_external:true` 重试；
   - 卡片：外部进程显示「运行中（外部启动）」徽标 + PID + 提示；操作后 `await renderModels()` 刷新。
3. **卡片状态**：`GET /api/models` 带 `pid/running/external`；停止按钮对 external 进程可用（二次确认）。

# 45 聊天图片与素材库分离（P23）

## 问题

微信聊天图片原先由 `agi/selflearn/media.save_image()` 写到
`agi/data/selflearn/media`（素材库目录），而 `tools/console/media_store.py`
扫描的正是这个目录 → 用户聊天图被误导入素材库（120 条素材里混入 3 张聊天图）。

## 目录语义

| 目录 | 用途 | 谁写入 | 谁扫描 |
| --- | --- | --- | --- |
| `agi/data/selflearn/media_chat/` | 聊天图片（attachments） | `media.save_image()` | 不扫描 |
| `agi/data/selflearn/media/` | 素材库（人工导入/素材） | 素材库导入 | media_store `_scan_dirs()` |
| `media/stickers/`、`wx_core/emoji_assets/` | 内置素材 | 资源文件 | media_store |

- `media.CHAT_MEDIA_DIR` / `chat_media_dir()`：聊天图；
- `media.MEDIA_DIR` / `library_media_dir()`：素材库；
- 聊天图仍登记 `attachments` 表（id/message_id/path/bytes/sha256）。
- `media_store.ensure_imported()` 双保险：
  1. 不扫描 `media_chat`；
  2. 候选文件路径若在 `attachments.path` 中（聊天图）→ 跳过。

## 迁移

```bash
# 先看（默认 dry-run）
python -m tools.migrate_chat_media \
  --db agi/data/selflearn/wechat_contacts/4260fd457d8355 \
  --library-db agi/data/selflearn/selflearn

# 确认后执行
python -m tools.migrate_chat_media \
  --db agi/data/selflearn/wechat_contacts/4260fd457d8355 \
  --library-db agi/data/selflearn/selflearn --apply
```

迁移逻辑：
- attachments 中路径位于素材库目录的文件 → 移到 `media_chat/`（同名冲突按 sha 区分）；
- 更新 attachments.path；
- 缺失文件的 attachment 只改 path 到 media_chat，**不删记录**（保留“曾收到过”的事实）；
- 删除 `media_assets` 中对应误导入路径的行；
- 迁移前把将移动文件/删除素材/缺失清单写到
  `E:\agent\backups\chat_media_migration_<ts>.json`；
- 二次运行幂等。

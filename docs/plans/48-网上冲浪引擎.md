# 48 网上冲浪引擎（P25）

小鱼自己上网「冲浪」：不是白看，产出（兴趣关键词 → 搜索 → 一句我的看法）沉淀进
兴趣库与 `surf_sessions`，**默认不主动发消息**（分享留到后续任务）。

用户原话（规则原始版本）＋ Lead 优化后的最终规则如下。

## 规则表

| 项 | 值 / 公式 |
| --- | --- |
| 窗口 | 每天 **10:00–22:00**（本地时间，左闭右开）；窗口外休眠、**不投骰子** |
| 用户明确要求 | 「帮我查/看看这个」→ **立即冲浪**，绕过窗口与门槛（`--reason user` / `POST /api/surf/trigger`） |
| 基准间隔 | 30 分钟（`surf_roll_interval_s = 1800`） |
| 实际 gap | `clamp(30 + round((0.9 - factor) * 12), 15, 45)` 分钟 |
| 骰子 | 1–6 均匀 |
| 执行判定 | `dice >= 3 且 dice * factor >= 2.4` |
| 时长 | `clamp(round(2 * dice * factor), 3, 12)` 分钟 |
| 条数 | `randint(2, min(20, max(3, round(dice * 3.5))))` |
| 因子 factor | 0.2–1.8（见下） |
| 状态文件 | `agi/data/selflearn/surf_state.json` |
| 记表 | memory 库 `surf_sessions` |

### 因子 factor

- 初值：`base = clamp(0.5 + (mood-0.5)*0.8 + (energy-0.5)*0.6 + N(0,0.25), 0.2, 1.6)`
  - `mood`：`mood_judge.load_state()` 的 `mood/100`（基线 70）；
  - `energy`：由 7 情绪推：`0.5 + 0.5*happy + 0.3*sweet - 0.5*sad - 0.4*worry`，夹紧 0–1；
  - **不额外调 LLM**（happy/sweet 高 → 因子高；sad/worry 高 → 低）。
- 执行后衰减：`dice = 6 → ×0.55`；`dice 3–5 → ×0.8`（下限 0.25）。
- 每次投骰（无论执行与否）：`+0.12` 向 1.0 恢复（上限 1.8）。
- 用户主动触发：`+0.1`（上限 1.8）。

示例（factor=1.0 起）：

| dice | 门槛 | 执行 | 执行后 factor |
| --- | --- | --- | --- |
| 6 | 6×1.0=6.0 | ✅ | 1.0×0.55+0.12=0.67 |
| 3 | 3×1.0=3.0 | ✅ | 1.0×0.8+0.12=0.92 |
| 2 | 点数不足 | ❌ | 1.12（只恢复） |
| 6（factor=0.35） | 6×0.35=2.1 < 2.4 | ❌ | 0.47 |

## 状态机

```
        ┌──────────── 窗口外（<10 或 ≥22）────────────┐
        │  休眠：不投骰；next_roll_ts = 下个 10:00      │
        └──────────────────────────────────────────────┘
                             │ 10:00 起每 30 分钟（gap 由因子微调）
                             ▼
                    投骰 dice(1–6)
                             │
              dice>=3 且 dice*factor>=2.4 ?
                    ┌────────┴────────┐
                   否                 是
                    │                 │
        surf_skipped(gate)      surf_executed
        factor += 0.12          冲浪 duration 分钟：取关键词 → 搜索 → my_take
        写状态、下次 gap          → interests.observe(source=self)
                                 → surf_sessions.summary(≤200)
                                 factor = decay(dice) + 0.12
```

用户触发（`--reason user`）走同一函数但 `force=True`：跳过窗口与门槛，`source=user`，
factor 先 +0.1。

## 冲浪做什么

1. `interests.next_search_keywords()` 取兴趣关键词（拿不到 → 天气/新闻占位）；
2. 可插拔取数：`surf.fetch(keyword, limit)`：
   - 优先 `agi/integrations/web_lookup.search`（w3-latency，联网搜索）；
   - 不可用/空结果 → **B站摄取兜底** `bili_ingest.search_videos`；
   - 两者都失败 → 本轮空，只记 error；
3. 每条结果生成一句 `my_take`（**本地规则模板**，不调贵 API，≤60 字）；
4. `interests.observe(..., source="self", ref={surf_session, keywords})` 记账
   （按兴趣 `self=0.2` 权重）；
5. 摘要写 `surf_sessions.summary`（≤200 字：看了几条 + 关键词 + 前几条 my_take）。

## 表结构（memory 库）

```sql
CREATE TABLE IF NOT EXISTS surf_sessions(
  id TEXT PRIMARY KEY, started_at REAL NOT NULL, ended_at REAL,
  dice INTEGER, factor REAL, executed INTEGER, duration_min REAL,
  items_seen INTEGER, keywords_json TEXT, summary TEXT, source TEXT, error TEXT
);
CREATE INDEX IF NOT EXISTS ix_surf_sessions_started ON surf_sessions(started_at);
```

由 `surf.connect()` 惰性建表（不改 `db.py` 的 schema 注册表）。

## 开关 / 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `surf_enabled`（gateway config.json） | true | gateway 是否拉起线程；false 时不启动 |
| `SURF_ENABLED`（selflearn/config.py + env） | true | 总开关；false 时 loop 空转 |
| `engine_enabled`（gateway 软开关） | true | false → 线程**暂停**（不退出），恢复后继续 |
| `surf_window` / `SURF_WINDOW` | `(10, 22)` | 窗口（env 形如 `10,22`） |
| `surf_roll_interval_s` / `SURF_ROLL_INTERVAL_S` | 1800 | 基准间隔（gap 公式里的 30 分钟） |
| `surf_max_items` / `SURF_MAX_ITEMS` | 20 | 单轮条数上限 |

## 与 proactive / mood 的关系

- **互不阻塞**：surf 是独立线程；只读 mood/兴趣，不发送、不写 messages/turns；
- 与 proactive 的唯一交集是「都读 `mood_judge` 快照」——proactive 用 mood 决定说
  不说，surf 用 mood/energy 决定冲浪因子；
- 默认**不触发任何微信发送**，因此不需要过 proactive 的静默/频率/内容闸门；
- engine 一键停（`/api/engine/stop`）会同时让 proactive 与 surf 暂停。

## 观测

日志（`gateway._record` → `agi/data/wechat/gateway.log`；独立运行写
`agi/data/selflearn/surf.log`）：

- `surf_roll`：`dice / factor / factor_after / effective / executed / gap_min / duration_min / items / next_roll_ts / source`
- `surf_executed`：本轮真冲了（含 duration/items）
- `surf_skipped`：`reason = outside_window | gate`
- `surf_error` / `surf_start_failed` / `surf_triggered`

HTTP：

- `GET /api/surf/status`（admin token）：`enabled / engine_enabled / window / in_window /
  factor / base_factor / mood / energy / last_dice / last_roll_ts / next_roll_ts /
  next_roll_in_s / today{rolls,executed,minutes} / last_summary / recent_sessions /
  thread_alive`
- `POST /api/surf/trigger`（admin token，body `{"reason":"user"}`）：后台立即冲一轮，
  返回 202 `{queued:true}`（不阻塞 HTTP）

CLI：

```bash
python -m agi.selflearn.surf_worker --status
python -m agi.selflearn.surf_worker --once --reason user    # 用户让她看
python -m agi.selflearn.surf_worker                        # 常驻（等价 gateway 线程）
```

## 风险 / 边界

- **不刷屏**：默认不发消息，只有日志与沉淀；后续分享需另做频控；
- **不阻塞聊天**：独立 daemon 线程，单轮失败只记 `surf_error`，不影响网关收发；
- 取数在第三方免费接口上（搜狗/必应/B站），失败即降级为空轮，不重试风暴；
- 冲浪不读用户私聊内容，只读兴趣库关键词（隐私面更小）；
- 状态文件损坏容错：解析失败回默认值（factor=1.0），不会让线程崩；
- 窗口按本地时区（`time.localtime`），与 night quiet hours 无关。

# 49 去网感腔调（P27）

## 问题

用户实测小鱼回复「天天拿寿司馋我，你中午这顿饭算是赢了」「能下饭就赢了」。
「赢了/输了」是网络玩梗/比赛比喻，不像普通朋友日常说话。

## 禁用词表

`赢了 / 输了 / 这波 / 拿捏 / 绝了 / 笑死 / 栓Q / 666 / 开摆 / 绷不住 / 血压(飙升|升高) / 算是…赢|输 / 只能算`

- 人设 prompt（`chat.system`）新增硬约束：不用网络梗/游戏腔/比赛比喻，像普通人聊天，
  不用「算是/只能算」总结式评价；
- 「互损」限定为轻的、生活化打趣，不拿对方的事做输赢评判。

## 生成后守卫（`agi/selflearn/chat.py` + `guard.py`）

1. `guard.slang_check(reply)` 命中；
2. 同一次生成预算内 **重写一次**：system 追加「把这几处换成普通人日常说话」；
3. 重写后仍命中 → `guard.strip_slang_clauses()` 删除命中分句，删空走 fallback；
4. 结果写入 `guard.slang_regenerated{before,after,issues,method}`，随 `trace.record_chat` 的 guard 字段留档；
5. 开关 `SLANG_GUARD_ENABLED`（默认 true，env 可覆盖）；关闭时该路径不做任何重写，回复逐字节不变。

## voice_polish 轻兜底

`voice_polish.polish_reply` 增加 `_deslang`：
`算是赢了→确实不错`、`算是输了→有点可惜`、`就赢了→就挺好`、`这波→这次`、
`拿捏→搞定`、`绝了→厉害`、`笑死→好笑`、`栓Q→无语`、`666→厉害`、
`开摆→算了`、`绷不住→忍不住`、`血压飙升→有点上头` 等；不改名词/数字/事实。

## 边界

- 不改 prompt_store 其它键、不改 gateway/console、不训练、不 commit。
- 网络梗识别是规则表，可能漏掉新梗；后续可扩表/用模型判别，但当前以低误杀为先。

## 实测（2026-10-27，真实 DeepSeek 20 条）

- 场景：吃饭 3、炫耀 2、吐槽 3、被夸 3、互损 3、日常 6。
- 禁用词命中：**0**（20 条原始回复全部扫描 `SLANG_RE`）。
- 结果：没有「赢了/输了/这波/拿捏/绝了/笑死/666/算是…赢」；改为「能下饭就够了，比啥都实在」
  「这么早就干完了，那晚上能踏实歇着了」「哪儿离谱了，我说的是实话啊」这类日常表达。
- 验证脚本：`python -m tools.persona.validate_slang --out <file>`。
- 说明：这一轮 20 条未触发重写（模型已按 prompt 避开），guard 重写/删分句路径由
  `test_slang_guard.py` 单独覆盖；线上命中时仍会走重写一次 → 删分句 → fallback。

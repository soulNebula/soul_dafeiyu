# M5 桌面化（Windows）

> 目标：把 801/802/803 三个本机服务包成一个双击即用的 Windows 桌面入口。
> 状态：**已完成（仅 Windows）**；非 Windows 未适配。
> 完成日期：2026-10-29

## 1. 范围

- 一键启动：801 网关 + 802 控制台 + 803 工作台（803 用 `idea/.venv`，cwd=`idea/`）；
- 桌面窗口：Edge/Chrome `--app` 模式（无地址栏），无浏览器时回落默认浏览器；
- 系统托盘：打开控制台 / 打开工作台 / 主动消息开关 / 紧急 STOP / 状态 / 日志 / 退出（单实例）；
- 开机自启：写「启动」目录 bat（`--autostart-registry` 可写 HKCU Run）；
- 状态与收尾：`--status` / `--stop`（只停自己拉起的 PID）；
- 入口：桌面快捷方式「小鱼桌面版」= `pythonw.exe tools\desktop\launcher.py --tray`（无控制台窗口）。

## 2. 实现

| 文件 | 职责 |
| --- | --- |
| `tools/desktop/launcher.py` | 零 pip 依赖启动器：服务探测/启动/健康检查、窗口、托盘、通知、自启、state |
| `tools/desktop/tray.ps1` | PowerShell + WinForms NotifyIcon 托盘（隐藏窗口、单实例） |
| `tools/desktop/desktop_entry.py` | PyInstaller 入口（可选构建；含崩溃日志） |
| `tools/desktop/build_exe.ps1` | PyInstaller 单目录构建脚本（本机不推荐） |
| `启动桌面版.bat` | 批处理入口（有控制台，方便传参） |

关键行为：

- 803 作为第三服务加入 `service_commands()`：`idea/.venv/Scripts/python.exe -m uvicorn app.main:app`，
  health=`/api/wb/health`（802 工作台新增的免 token 健康检查）；
- 窗口复用：只复用「标题含 Soul Console」的已完成窗口；空白/残留窗口先关掉再开，
  开窗后等 25s 验证，失败重开一次，仍失败回落默认浏览器；
- 弹窗治理：所有 PowerShell 查询隐藏执行（`CREATE_NO_WINDOW`），窗口标题用 Win32
  `EnumWindows/GetWindowText` 读取；管理员启动时改用普通权限 `explorer` 打开浏览器，
  避免 Edge「现有实例正在以提升的权限运行」；
- PyInstaller exe 在本机被安全软件拦成 `0xc0000142`，因此不作为推荐入口。

## 4. 已知限制

1. **仅 Windows**：UIA、微信窗口、Edge app 参数都是 Windows 行为。
2. **首次打开慢**：Edge 独立 profile 冷启动约 20–30s；之后复用窗口秒开。
3. **exe 不推荐**：本机安全软件/加载器拦截（0xc0000142）；换机器可尝试 `build_exe.ps1`。
4. **Tauri/WebView2 自绘窗口未做**：当前是「Edge app 窗口 + 托盘」的桌面壳；需要更原生壳再立项。
5. **管理员启动被限制**：会自动回落普通浏览器；托盘部分功能（STOP 等）仍依赖 802 token 权限。

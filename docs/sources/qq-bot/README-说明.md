## 二、直接吸收的三条（已写进 18/19）

1. **隐式信号只记不训。** 用「对话延续」当正样本，会训出一个话痨客服——正好毁掉角色卡里「允许潜水、不必有求必应」的设计。
2. **inner 不写具体人名。** 写了「对某人有点不爽」，下一轮说漏嘴就是事故；字段只留 mood/want 这类模糊指代，且提示词硬写「只给自己看」。
3. **控制台先做、聊天侧后做。** 群聊里加 👍/👎 会被群友看见、还要处理乱点；先在管理端补标。

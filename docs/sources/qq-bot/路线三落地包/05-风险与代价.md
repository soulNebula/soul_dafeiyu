# 05 · 风险与代价

> 前面几份都在说"你有多少现成的"，这份只说会疼的地方。
> 每条都标了：**概率 / 影响 / 怎么防**。

---

## 零、最大的风险：训练目标和人格目标是相反的

这是整件事里最隐蔽的坑。

你的角色卡和 preset 花了大量篇幅写：
> 「不是每条消息都要回」「允许潜水」「不要有求必应」「别人要推荐可以不接」「你不是客服」

而方案推荐的隐式反馈是：
> 「根据你是否继续深入话题来判断」「对话延续度越高 = 越好」

这两句话在训练时是**直接对冲**的。用"用户继续聊"当正样本，模型会学到：
- 多问一句、多留话头、延长对话；
- 顺着对方说、少拒绝、少潜水；
- 结果是**一个话痨版的客服**——正好是你最不想要的那种。

**概率**：如果用隐式信号训练，几乎必然。
**怎么防**：
1. 隐式信号只用于**分析**（看某类回复后用户是否流失），不进训练标签；
2. 训练标签只用显式评分；
3. 如果一定要用隐式，只用**负信号**（"回复后对方立刻冷场/结束对话"），不用正信号。

## 一、技术风险

### 1. 灾难性遗忘 — 概率高 / 影响中
每周只喂最近 50-100 条新样本，模型会快速忘记更早的能力，且新样本里如果全是某一种语气（比如这周群里都在玩梗），它就被同化成那一种。

**怎么防**：
- 训练集里**固定混入 30-50% 历史样本**（replay buffer），不要只喂新的；
- 不要在一个 adapter 上连续 merge 十几轮——**每轮从 base 重训**，保留可回退的检查点。

### 2. 人格漂移到最近群氛围 — 概率中 / 影响大
这周群里在骂人，模型学会了；下周群里在发疯，它又变了。三周后你已经说不清"它本来是什么样"。

**怎么防**：留一份**冻结的基准 eval set**（50 条固定上下文），每轮训练后都跑一遍，对比"有没有变得不像原来那个它"。

### 3. 没有评估的盲训 — 概率高 / 影响大
50 条样本训一轮，变化往往只是腔调。凭感觉判断会被**最近一次惊艳回复**主导，你会以为变好了。

**怎么防**：G2 的 20 组 A/B 盲评。这是唯一的解药。

### 4. 小模型的理解力天花板 — 概率高 / 影响中
1.5B-1.7B 读群聊时，分不清"谁在跟谁说话"、看不出反讽、接不住多层梗。它写出的状态标签会**拉平**大模型的回复。

**怎么防**：只让它做"复现大模型判断"这种窄任务；评估比的是**下游回复质量**，不是 inner 文本相似度。

### 5. 状态内容外泄成社交事故 — 概率低 / 影响高
如果 `inner` 里写了"对阿澈有点不爽"，而模型下一轮把这句话说出去了——这在群里是真的会出事的。

**怎么防**：
- `inner` 字段**不要写具体人名**，用"群里某人"这类模糊指代；
- 或者只存 `mood` / `want` 两个字段，不存对象和原话；
- 提示词里硬写一条：**内心状态只给自己看，不要直接复述给任何人**。

## 二、成本的真实结构

### 钱：几乎可以忽略
- 每轮多 200-400 token 的独白：按 V4 的价格，一天几十轮也就几分到几毛；
- 小模型：电费，可忽略；
- 训练：本地跑，除了时间不花钱。

**💭 判断**：方案原文说"几十元一次"，指的是租算力。你自己有卡的话，钱根本不是问题。

### 时间：这才是真正的成本

| 项目 | 每次 | 频率 | 三个月合计 |
|---|---|---|---|
| 整理/清洗数据 | 1-2h | 每周 | 12-24h |
| 训练 + 部署 | 1h | 每周 | 12h |
| 评估对比 | 2-3h | 每周 | 24-36h |
| **合计** | 4-6h | 每周 | **50-70 小时** |

50-70 小时是什么概念：够你把 Step 0-2 重做五遍，或者把整个项目的测试覆盖率翻一倍。

**所以路线三真正的取舍不是"钱 vs 效果"，是"50 小时换一个可能更好的语气"值不值。**

## 三、隐私与伦理（这条要认真看）

你的训练数据是**真实群聊**，里面有别人的发言。

1. **他们没同意被训练**。即使是在你自己的群里，把群友的话拿去微调模型，也需要至少打个招呼。
2. **微调后的模型可能复述原话**。SFT 数据里的原句有概率被模型在别的场合吐出来——这比"日记泄漏"更隐蔽，因为你自己都不会察觉。
3. **不要公开发布微调模型**。一旦发布，就无法收回。

**最低限度的做法**：
- 模型只本地用，不外传、不发布、不上传任何平台；
- 训练前跑一遍 `npm run privacy-scan`，并对人名/手机号/地址做替换；
- 训练目标只覆盖"状态生成"这种短文本，**不要让模型学"聊天原文"**——这样它没有机会记住群友说过的话。

> 💭 这也是"只蒸馏状态、不训练聊天"的另一个理由：它同时降低了隐私风险和灾难性遗忘风险。

## 四、期望管理

### "涌现" — 基本不会从微调里来
路线三说"要保留涌现的可能性"。但 SFT 的本质是**让模型更像训练数据**，也就是**更可预测**，方向正好相反。

真正的"意外时刻"来自：记忆 + 主动唤醒 + 不确定性。这三样你已经有了（见 [01 第 11 项](01-免做清单.md)）——**不训练也能看到它主动开口**。

### "每周微调一次" — 不是纪律问题，是评估问题
方案把它写成"保持节奏"。但有节奏没评估，等于每周花 5 小时随机调整一次人格。真正该保持的节奏是"每周评估一次，有明确提升才替换"。

### "只属于你的 AI" — 这句是真的，但载体不是权重
它对你的了解来自**记忆、角色卡、上下文**，这些你已经有了。权重只是把这些变得更"顺口"，不是变得更"懂你"。

## 五、什么情况下应该停手

出现任意一条，就停：

1. **G2 没过**（20 组 A/B 里 B 赢不到 12 组）→ 内心状态对回复没有可感知影响，后面全部没意义；
2. **三个月后，除了"语气更稳"没别的变化** → 说明这条路的天花板就在这里；
3. **维护成本超过乐趣** → 每周 5 小时如果变成负担，它就不再是"养一个东西"，而是"维护一个系统"；
4. **你开始不敢改 prompt 了** → 说明微调把系统变得不可理解，这时候应该回退到"全 prompt"方案，删掉 adapter。

---

## 六、和"什么都不做"比

| | 停下 | 走完 Step 0-2 |
|---|---|---|
| 成本 | 0 | 约 2 天 + 2 周观察 |
| 得到 | 现在这个能聊的 AI | 一个会"记得上次心情"的 AI + 一套数据 + 一个明确的判断 |
| 风险 | 无 | 低（都可回滚） |

**💭 建议**：至少走完 Step 0-2。它便宜、可回滚，而且无论最后训不训小模型，你会得到两样东西：一个更好的体验，和一个"我到底要不要继续投入"的答案。

Step 3 才是有争议的部分——那 50 小时值不值，取决于你要的是"更好用的陪伴"还是"自己训出来的东西"。前者不值得，后者很值得，但那是另一个价目表。

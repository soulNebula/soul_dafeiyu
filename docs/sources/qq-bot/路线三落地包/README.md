# 路线三落地包

> 2026-10-24 · 对照代码：`qq-bridge` v0.2.1-r1（适配 DSH 0.2.1-rc.2）
>
> 这份包只回答一个问题：**做「路线三」的时候，哪些东西你已经有了、不用再重做。**

## 一分钟看完

路线三要你从零搭十几样东西。逐项对完你的项目后：**8 样可以直接复用，4 样半有，真正要新建的只有 3 个零件 + 1 套评估。**

### ✅ 不用再做的（复用度 ≥ 70%）

| # | 方案要求你做的 | 你已有的等价物 | 复用度 |
|---|---|---|---|
| 1 | 聊天界面（对话窗口） | QQ 本身 + 本地 Web 控制台 | 100% |
| 2 | 对话日志数据库 | `state/*.json` + `*.jsonl` + DSH 会话历史 | 95% |
| 3 | 调 API 大模型当回答引擎 | DSH agent（多 provider/多模型） | 100% |
| 4 | 人格/角色系统 | `roles/*.md` + `qq-chat*` preset，两层分离 | 100% |
| 5 | 记忆库 | `qq_memory_*` 四件套（话题/念头/印象） | 90% |
| 6 | 多会话隔离（私聊/各群） | 会话映射 + 每会话独立 DSH 会话 | 100% |
| 7 | 把独白注入系统提示 | `buildWakePromptV2` 多段拼装管线 | 95% |
| 8 | 成本监控 | 峰谷分时 + 缓存三桶 + 按群/好友/轮次下钻 | 100% |
| 9 | 安全边界（别让 AI 乱来） | 工具白名单、无本地工具、MCP 安全子集 | 100% |
| 10 | 稳定性（崩溃/断线/重复启动） | 守护重启、单实例锁、断线补投、mux 重连 | 100% |
| 11 | 主动行为（"涌现时刻"） | 主动唤醒/潜水/等待/已读水位 | 100% |
| 12 | 回归测试 | 几十个 `scripts/test-*.mjs` | 100% |

### 🟡 半有，只差一小块

| # | 方案要求 | 现状 | 补什么 |
|---|---|---|---|
| 13 | 记录"内心独白" | **通道已有**（v2 下 AI 文本不发 QQ，天然是独白），只是不落盘 | 存成结构化 JSON，下轮注入 |
| 14 | 小模型服务 / 模型热切换 | 有 MCP + preset 两套外挂机制，没接本地模型 | 挂一个 MCP server 或本地 HTTP 边车 |
| 15 | 训练集 | 原始数据全在，缺聚合/导出 | 一个 `export-dataset.mjs` |
| 16 | A/B 对比实验 | 模式切换、逐会话选模型够用，缺自动分流 | 手动切 + 看板对比即可，不必自动化 |

### ❌ 真没有，必须新建

| # | 零件 | 工作量 | 卡点 |

## 工作量重估

| 方案原文的节奏 | 原文估计 | 你的实际 |
|---|---|---|
| 第一周：搭原型（界面+库+独白+注入） | 1 周 | **半天**（只有独白落盘要写） |
| 第二周：积累数据 | 1 周 | **已经在自动发生**，补个打分入口就行 |
| 第三周：第一次微调 | 1 周 | **推迟到第 4-6 周**，因为要先有 eval set |
| 第四周起：每周迭代 | 持续 | 取决于你要不要训小模型（见 05） |

## 一句话

路线三原文假设你从零开始，所以给了四周工期；按你现在的代码，**"第一周"那部分已经完成了**，
真正该花时间的不是搭系统，是攒数据、定评估、然后决定要不要训那个小模型。

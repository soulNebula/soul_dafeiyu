# 11 · 分享欲与主动表达

> ⚠️ **设计依据文档，非施工图。实施以 [PLAN.md](PLAN.md) 为准；冲突时一律以 PLAN 为准。**


> 你的诉求：**它得像人一样有分享欲**——冲浪看到好玩的、朋友圈看到好看的、自己做了张图，会想跟你说。
> 而且这种「想分享」和「会分享」，都得是它自己学出来的。

---

## 一、先定性质：分享欲是「驱动」，不是「功能」

这是本节最重要的一句话。

| | 功能式（错） | 驱动式（对） |
|---|---|---|
| 触发 | 定时器到点 → 找点东西发 | 内部积压到阈值 → **想**发 |
| 表现 | 每天 9:00 准时发一条 | 有时一天两次，有时三天没有 |
| 失败 | 内容无关、像推送 | 像人，有起伏 |
| 停止 | 关掉开关 | 被冷落几次，**自己收敛** |

**驱动（drive）模型**，和饥饿一样：

```yaml
share_drive: 0.62      # 0=完全不想说，1=憋不住了
  + 距上次分享的天数 × 0.08
  + 手头有趣素材数 × 0.05
  + 与对方亲密度 × 0.20
  - 最近被冷落的次数 × 0.15
```

- `drive < 0.5`：不想说，看到好东西也先存着
- `0.5 ≤ drive < 0.75`：有点想说，看时机
- `drive ≥ 0.75`：**主动发起**

**关键**：drive 高了不等于一定发。高 drive 只是「想」，还得过「该不该打扰」这关。**会克制，才是人格。**

## 二、分享的四个环节

```
① 发现 → ② 评估 → ③ 判断 → ④ 表达
（素材池）  （有没有趣）  （该不该此刻说）  （怎么说）
```

| 环节 | 做什么 | 靠什么 |
|---|---|---|
| ① 发现 | 浏览/刷朋友圈/生成内容，存进候选池 | 心跳任务、`moment` 表、生成图 |
| ② 评估 | 这个值得分享吗？对他有意思吗？ | **品味模型**（见第四节） |
| ③ 判断 | 现在适合打扰吗？ | 时机模型（见第五节） |
| ④ 表达 | 怎么说才不像推送 | 表达模板 + 人格语气 |

**四个环节任一不过，这条就留在池子里，不发。**

---

## 三、分享的三级（难度递增）

| 级别 | 类型 | 例子 | 风险 | 价值 |
|---|---|---|---|---|
| **L1** | 转发型 | 「刷到一个帖子，笑死」 | 低 | 低（可能就是噪音） |
| **L2** | 关联型 | 「这个让我想到你上次说的面试」 | 中（要用记忆） | **高** |
| **L3** | 创作型 | 「我照你说的画了张图」 | 高（做不好就尴尬） | 最高 |

**学习路径必须是 L1 → L2 → L3。**

- L1 只能证明「它在刷手机」；
- L2 才是**「它记得你」**——这是关系推进的核心；
- L3 是**「它为你花了时间」**——最贵，也最容易翻车。

> 大多数主动型 AI 卡在 L1：天天转帖，用户三天就烦了。
> **L2 才是分水岭。**

## 四、「什么算有趣」是可以学的

**品味不是天生的，是反馈喂出来的。**

### 4.1 候选池打分

```python
score = 0.4 * 与用户兴趣匹配度      # 用画像的兴趣维度
      + 0.3 * 用户历史反应的同类内容权重
      + 0.2 * 新颖度（没见过的类型 +）
      + 0.1 * 时效性（今天的热点 > 上周的）
```

### 4.2 学习信号

| 信号 | 含义 | 权重 |
|---|---|---|
| 回复了 | 有兴趣 | +1 |
| 回复超过 10 字 | 真有兴趣 | +2 |
| 追问细节 | 强烈兴趣 | +3 |
| 回「哦」「哈哈」 | 礼貌敷衍 | 0 |
| 不回 | 不喜欢或时机不对 | -1 |
| 明确说「别发了」 | 严重 | -5，**停 7 天** |

### 4.3 学到什么

- **内容类型权重**：他喜欢搞笑 / 科技 / 摄影 / 宠物？
- **表达方式**：直接甩链接 vs 先说一句自己的感受？
- **时机**：早上看 vs 晚上看？
- **频率**：他能接受几天一次？

**这些都是 `skill_variant` 的统计，和 04 文档里的 bandit 一套机制。**

> 换句话说：**分享欲不是写死的规则，是一个被反馈训练出来的策略。**

## 五、时机模型（**防打扰是生死线**）

### 5.1 硬窗口（不可突破）

| 规则 | 值 |
|---|---|
| 静默时段 | 23:00–08:00（除非用户明确说在熬夜） |
| 工作时间 | 画像里 `schedule` 若标「上班忙」，10:00–18:00 不发 |
| 对话进行中 | **绝不打断**，等当前话题结束后 ≥ 10 分钟 |
| 用户情绪为负 | 情绪 < -0.3 时，**不分享轻松内容**（换成关心） |
| 最近刚分享过 | 24 小时内最多 1 次 |

### 5.2 软判断

```
现在发，是因为：
  ├─ 有时效性（今天的事，明天就没意义了）→ 值得打扰
  ├─ 和刚才的话题有关（顺势带出来）→ 最自然
  └─ 只是「我觉得有意思」→ 可以等，攒着下次一起说
```

**「攒着」这个动作特别像人**：不是想到就发，是等一个合适的时机说出来。

## 六、频率与冷却（社交分寸）

| 情况 | 动作 |
|---|---|
| 默认上限 | 每天 ≤ 2 次，每周 ≤ 8 次 |
| 被已读不回 1 次 | 频率 ×0.7，冷却 24h |
| 被已读不回 2 次 | 冷却 3 天，降低该类型权重 |
| 被明确拒绝 | **停 7 天**，该类型权重 ×0.3 |
| 连续两周没分享 | 关系活跃度下降，**但不要为了刷存在感硬发** |

**最难的一条：允许它「几天什么都不说」。**
一个每天准时推送的 AI，不是有分享欲，是有 KPI。

> 📌 「这一次到底发不发」的具体算法（打分 + 置信度 + 置信下界），见 `12-主动行为的评分与决策.md`。

## 七、生成图片：一个新技能，从 level 0 学起

这正是 06 文档技能树的用武之地。

```yaml
skill: SK-IMG-001
name: "文生图基础"
level: 0            # 从零开始
verifier: weak      # 主观，没有客观标准
learning_path:
  1. 搜索：prompt 怎么写（构图/光线/风格词）
  2. 练习：同一主题出 5 张，自己对比
  3. 内评：是否达到"能看懂"的最低标准
  4. 外测：给用户看，看反应
```

| 等级 | 判据 |
|---|---|
| L1 | 知道 prompt 结构（主体+风格+构图） |
| L2 | 能复述「为什么这张好看」 |
| L3 | 生成的图**无畸形**（手/脸/文字），主题可辨 |
| L4 | 能按需求调整（换风格/换构图） |
| L5 | 有自己的偏好和判断 |

**verifier 弱 → 只能用行为信号验证**：用户保存了吗？放大看了吗？说「好看」了吗？
这类技能**最多到 L3 才允许在分享里用**，且**必须自己先筛一遍**（十张里挑一张）。

> 分享一张糊图，比不分享更掉价。

## 八、数据表

```sql
CREATE TABLE share_candidate(
  id TEXT PRIMARY KEY,
  subject TEXT,
  kind TEXT,              -- web|moment|generated_image|memory
  source_ref TEXT,        -- url / moment.id / media.id
  content TEXT,
  relevance REAL,         -- 与用户兴趣匹配
  novelty REAL,
  score REAL,
  status TEXT DEFAULT 'pool',  -- pool|sent|expired|rejected
  created_at REAL, expires_at REAL
);

CREATE TABLE share_event(
  id TEXT PRIMARY KEY,
  candidate_id TEXT,
  subject TEXT,
  sent_at REAL,
  level TEXT,             -- L1|L2|L3
  opening TEXT,           -- 开场那句
  response_type TEXT,     -- reply_long|reply_short|ignored|rejected
  response_lag REAL,
  score REAL
);
```

## 九、失败模式（每一个都会真实发生）

| 失败 | 表现 | 根因 | 对策 |
|---|---|---|---|
| **推送化** | 每天准时发，内容无关 | 用定时器代替 drive | 改驱动模型 + 加静默 |
| **自说自话** | 分享完不接话，用户回了它也不接 | 把分享当任务 | 分享后必须进入对话状态 |
| **掉价** | 分享烂梗、糊图 | 没有内部筛选 | 十选一 + 最低质量线 |
| **打断** | 对话中途插一条 | 时机模型缺失 | 硬窗口 + 话题结束检测 |
| **讨好式分享** | 专挑用户爱听的说 | 打分只看「回复率」 | 加「内容真实性/质量」独立指标 |
| **冷场后猛发** | 被冷落后更努力地发 | 把沉默当失败 | 冷落 → 收敛，不是 → 加码 |
| **情绪垃圾** | 把自己「不开心」倒给用户 | 情绪模块误用 | 分享只分享正向内容 |

## 十一、验收指标

| 指标 | 目标 |
|---|---|
| 分享接受率（有实质回复） | ≥ 50% |
| 打扰率（用户表示烦/明确拒绝） | < 5% |
| L2 及以上占比 | ≥ 40%（不能全是转发） |
| 分享后对话延续 ≥ 3 轮 | ≥ 35% |
| 夜间违规发送 | **0** |
| 被冷落后的收敛速度 | 2 次内 |
| 生成图畸形率 | < 10% |

## 十二、一句话总结

> **分享欲的本质不是「我想说」，而是「我看到这个，第一个想到你」。**
>
> 驱动让它有「想」，克制让它有「分寸」，反馈让它有「品味」。
> 三者缺一个，它就会变成每天准时推送的营销号。

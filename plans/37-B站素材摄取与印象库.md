# 37 B站素材摄取与印象库（P12-A）

## 数据流

```
bilibili_api（进程内，不走 MCP）
  → fetch_video：元信息/字幕/热评/弹幕
  → local keyword_extract（8125）
  → local ingest_summary（8125）
  → API video_understanding（强制 API）
  → API share_copy
  → memory 库 bili_impressions
```

代码：`agi/integrations/bili_ingest.py`；凭证默认
`~/.dsh/bili-duty/bili_credential.json`（env `BILI_CREDENTIAL_PATH` 可覆盖）。

## 表结构（memory 库，P7-e 拆分后）

`bili_impressions`：

| 字段 | 含义 |
| --- | --- |
| id / bvid | 主键 / BVID（UNIQUE） |
| title / owner / owner_mid / duration_s / cover_url | 元信息 |
| summary / topics_json / emotion | 本地摘要 |
| value / why / my_take | API 真理解（value 0–1；my_take 第一人称 ≤60） |
| share_line | API 分享语（≤40） |
| subtitle_len / subtitle_missing | 字幕字数/是否缺失 |
| comments_json / danmaku_json | 热评 top20 / 弹幕抽样≤100 |
| meta_json | 分区/tags/播放/步骤耗时等 |
| created_at / shared / shared_at | 创建/是否已分享 |

同 BVID 二次 ingest 用 `ON CONFLICT(bvid) DO UPDATE` 更新，不新增行。

## 四步路由

| 步骤 | purpose | 路由 |
| --- | --- | --- |
| 话题 | `keyword_extract` | local 8125（fallback API） |
| 摘要/情绪 | `ingest_summary` | local 8125（fallback API） |
| 真理解 | `video_understanding` | **API 强制**（`must_api`） |
| 分享语 | `share_copy` | API（fallback local） |

每步记录 `{backend, usage, latency_ms}` 到 `meta.steps`；ingest 返回 `steps` 与耗时。

## 失败/缺失处理

- 抓取失败：重试 1 次，仍失败返回 `bili_fetch_failed`；
- 未登录/凭证不全：`bili_not_logged_in`；
- 无字幕：`subtitle_missing=true`，summary/understanding 使用标题+简介+评论，prompt 明确不得编造；
- LLM JSON 坏输出：重试 1 次；仍失败 `bili_ingest_failed`，**不写半成品**；
- `--dry`：只抓素材，不调用任何模型、不落库。

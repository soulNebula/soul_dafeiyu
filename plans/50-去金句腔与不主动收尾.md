# 50 去金句腔与不主动收尾（P28）

## 问题

用户反馈：
1. 小鱼会说「不高级但耐看」「这默契先存着」「买完就踏实了」这类**金句腔/伪深刻短评**，像文案不像朋友；
2. 一个话题聊完她会说「那先这样，忙你的去」然后直接结束，像完成任务。

## 禁用规则

### 金句腔（canned）

正则至少覆盖：
`不高级.*耐看|耐看|挺稳|蛮稳|不会出错|默契|收下了|接住了|记下了|存着|踏实了|心里舒坦|花在刀刃上|这波不亏|值了|算下来`

prompt 硬约束：
- 不写金句式短评（…但耐看/挺稳的/买完就踏实了/这默契先存着/我接住了）；
- 不说“收下/接住/存着/记下了”这类腔调；
- 只说具体的事和感受，不总结、不评价得漂亮。

### 主动收尾（closing）

正则：`那先这样|忙你的去|你先忙|回聊|改天聊|不打扰了`

仅当用户上一条**不含** `忙|睡|晚安|再见|bye|出门|上班|下班|走` 时判违规。
prompt：除非对方明说要去忙/要睡/再见，否则不要主动结束对话；
话题自然说完就接一句自己的事（或轻问题，问句配额 ≤2/10）。

### 元自我

prompt：不聊自己怎么说话/记性/说话习惯这类“元自我”，不解释自己。

## 生成后处理

`guard.canned_check(reply, user_text)` → 命中 canned 或 closing（未被允许）：
1. 同预算重写一次（system 追加普通说话/不主动收尾要求）；
2. 仍命中 → `strip_canned_clauses` 删命中分句，删空 fallback；
3. 记录 `guard.canned_regenerated{before,after,issues,method}`，进 trace。

- 开关 `CANNED_GUARD_ENABLED` 默认 true（env 可覆盖）。
- P27 的 slang 守卫仍在；两者可同时命中，合并一次重写。
- voice_polish 轻兜底：`挺稳的→挺好的`、`买完就踏实了→买完就安心`。

## 实测（真实 DeepSeek 30 条）

场景：吃饭 4、炫耀 3、吐槽 3、被夸 3、互损 3、日常 6、话题结束 3、用户要忙/睡 3、图片评论 2。

- 金句腔命中：**0**
- 无许可主动收尾：**0**
- 问句率：**3.3%**（≤20%）
- 示例：`今天聊了好多` → `是啊，话头一开就收不住 / 我这会儿还挺精神的，你呢，眼睛困了没`
  `我去忙了` → `行，忙你的`（用户明确要走，允许收尾）
- 脚本：`python -m tools.persona.validate_canned --out <file>`。

## 测试

chat 重写/仍命中删句、开关关闭不重写、prompt 含规则。

## 边界

- 不改 gateway/console/trace 结构；不训练；不 commit。
- 规则是启发式，可能漏新金句；后续可扩表/模型判词。

# 53 小鱼的日记（P31）

用户要求：**每天晚上 23:00 让小鱼写一篇自己的日记**，在本机创建文本文档，写今天的情感
和经过、发生了什么；**她想写什么就写什么**（自由发挥，不是工作报告）。

## 数据来源（只读）

`collect(path, date)` 汇总当天（本地 00:00–24:00）的素材：

| 来源 | 表 / 文件 | 取什么 |
| --- | --- | --- |
| 对话 | `messages`（主库 + 各联系人库） | 他说的话、她回的话、被跳过/被否定的、图片语音（网关写成文字占位）、按小时分布 |
| 回合 | `turns` | 条数、`feedback`（好/一般/差） |
| 主动消息 | `gateway.log` 的 `proactive_send` | 她自己开的口（内容/时间/intent_kind/他回没回） |
| 冲浪 | `surf_sessions` | 几轮、共几分钟、刷了几条、关键词、最近一轮摘要 |
| 心情 | `mood_timeline` | 起→收、高低点、均值、原因；没有判定时回退 `state.self_state` 快照 |
| 人格 | `persona_layers` | 当天新变化（key/layer） |
| 兴趣 | `interest_events` + `interests` | 什么变热了（delta 汇总）、平时最在意什么 |
| 视频 | `bili_impressions` | 当天刷到的 B 站视频 + 她自己写的 my_take |

压缩成 **≤3000 字**的「今天的记录」给模型回忆（均匀抽样对话，保留开头和结尾；
超预算先砍对话抽样，再整体截断）。

## 生成（DeepSeek API）

- 人格：`prompt_store.get("chat.system")` 的**前半人设部分**（热加载）→ 兜底
  `chat.SYSTEM` 前半；
- 指令（用户原话整理）：

  > 用你自己的口吻写今天的日记（第一人称，300-600 字）：写记得的事、情绪起伏、
  > 想不通的地方、想跟他说但没说的；可以写刷到的东西和自己的看法；不要列清单、
  > 不要写成汇报、不要总结今天学到了什么；该短就短，今天没什么事就写短一点。

- 额外规矩：只输出正文（无标题/日期/markdown/署名）；只写记录里真实发生的事；
  不提「素材/数据/记录/总结/今天学到」；语气像平时说话；
- 调用：`agi.selflearn.llm.Client.chat(purpose="diary", max_tokens=1600, temperature=0.9)`；
- 清理：去标题/日期/引号，合并空行，硬上限 2400 字；
- 判定：正文 <40 字视为失败 → fallback。

## 落盘

```
agi/data/diary/
  2026-10-27.txt        # UTF-8（无 BOM），用户要的「本机文本文档」
  index.jsonl           # 一行一篇：date/path/chars/mood_avg/generated_at/fallback/model
```

- 幂等：当天文件已存在且 `force=false` → 直接返回 `skipped:true`（不调 API、不改文件）；
- `force=true` 才重写；`index.jsonl` 同一天只保留一行（原子写 tmp+replace）；
- **失败策略**：API 失败 / 无内容 / 太短 → 规则 fallback（只陈述事实 + 一个情绪词，
  ≤300 字，`fallback:true`）；绝不写空文件；连 fallback 都为空才返回 `{ok:false}`。

## 定时

gateway 内独立线程（`gateway-diary`，daemon、单例幂等、异常不致命）：

- 每 **60s** 检查一次；
- `diary_enabled`（默认 true）独立开关；`diary_hour`（默认 23）之后才写；
- 当天已写 → `diary.write` 返回 skipped，不重复调 API；
- 失败退避 **30 分钟**再试（避免 API 故障时每分钟刷量）；
- **`engine_enabled=false` 时也允许写**：写日记不打扰用户，只是本地沉淀；
- 启动晚于 23:00 也会在 60s 内补写当天。

## 开关 / 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| gateway `diary_enabled` | true | 是否拉起日记线程 |
| gateway `diary_hour` | 23 | 几点后允许写 |
| selflearn `DIARY_ENABLED`（+env `DIARY_ENABLED`） | true | `diary.enabled()` 总开关 |
| selflearn `DIARY_HOUR` | 23 | `diary.diary_hour()` |
| selflearn `DIARY_DIR` | `agi/data/diary` | 目录（env `DIARY_DIR` 可覆盖，测试用） |

CLI：

```bash
python -m agi.selflearn.diary --date 2026-10-27          # 默认今天
python -m agi.selflearn.diary --date 2026-10-27 --force  # 重写
python -m agi.selflearn.diary --print                    # 打印正文
```

## 控制台 API（只读 + 手动，admin token）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/diary/latest` | 最新一篇：`{ok,date,text,chars,mood_avg,fallback,generated_at}` |
| GET | `/api/diary/list?limit=30` | 日期列表（新→旧） |
| GET | `/api/diary/get?date=YYYY-MM-DD` | 指定日期正文（缺失 404） |
| POST | `/api/diary/write` | 立即补写今天（幂等；body `{"force":true}` 重写） |

不做页面（后续可加「日记」页）。

## 隐私 / 风险

- 日记含用户对话，**只写本机** `agi/data/diary/`（git 忽略）；
- 生成时素材会发给 **DeepSeek API**（产品行为：模型在云端写正文）；关掉
  `diary_enabled` 可完全停止；已写日记不会被再次上传；
- 日记不发送到微信，不进入 chat 上下文（除非以后另做功能）；
- 人格 prompt 里已有「不编造」约束；日记 prompt 再强调「只写记录里发生过的事」；
- 生成失败时 fallback 只有事实 + 情绪词，不编细节。

## P37：真实后台状态 + 禁止旧故障入驻

- `collect()` 注入 `activity`（复用 `simple_tick.today_activity_context()`）：
  `bili_today: ran/picked/report_date` + `surf_today: sessions/items`，同时写进 materials；
- prompt：必须有一句真实状态句（如「今天后台刷了2轮，挑中0条；自己上网看了9轮、翻了27条」）；没刷到就写「今天没看到什么」；禁止写网络坏了/页面打不开/连不上/刷不了B站，也不要把旧对话里的故障说法当事实；
- 素材过滤：旧消息中命中 `false_failure` 或「时钟不太准/让他看手机/没刷成」的片段不进入日记素材；
- 生成后 `guard.false_failure_check` 命中 → 重写一次；仍命中 → 删分句；
- 实测 2026-10-27 重写：425 字，正文无「网出不去/刷不了B站/页面转圈」，末尾写「今天后台刷了2轮，挑中0条；自己上网看了9轮、翻了27条。」

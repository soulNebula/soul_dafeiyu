# 54 · 自我叙事（P32）

> 用户长期方向：让小鱼慢慢有自己的「意识」、越来越像人。先做地基：**自我叙事**。
> 本周记/叙事只在本机生成与保存；不改 chat/gateway/console（接线等 Lead 确认）。

## 1. 数据流

```text
近 7 天：
  memory DB（messages/turns/inner_states/feedback/surf_sessions/bili_impressions）
  persona DB（interests / persona_layers）
  agi/data/diary/**/*.md（P31 日记，若还没有则空）
  agi/data/train/daily/*.jsonl（P30 被否定事件）
        │ collect_week()
        ▼
DeepSeek：第一人称周记 300–500 字
        ▼
DeepSeek：提炼 ≤120 字自我叙事
        ▼
persona_layers core `self_narrative`
  observe → approve(approved_by="weekly_review") → active
  旧值归档 narrative_history.jsonl
        ▼
agi/data/diary/weekly/YYYY-Wxx.md
```

## 2. 文件与函数

`agi/selflearn/self_narrative.py`：

| 函数 | 作用 |
| --- | --- |
| `collect_week(db_path=..., now=..., diary_dir=..., daily_dir=...)` | 只读汇总近 7 天素材（表缺失自动降级） |
| `weekly_review(..., client=None, force=False)` | 生成周记+叙事、写 daily weekly md、写 core 层、归档旧值；同周文件存在时幂等跳过 |
| `maybe_weekly(now=..., weekly_dir=..., enabled=True)` | gateway 周日 23:30 检查点（不写文件），返回 should_run/reason/next_run |
| `inject_line(db_path=...) -> str` | chat 注入用 ≤80 字；没有叙事返回 `""`（chat 侧空串逐字节不变） |
| `current(db_path=...) -> dict` | `{ok,text,found,id,approved_by,updated_at,version}` |
| `history(path=..., limit=20) -> list[dict]` | 读 `narrative_history.jsonl` |

另有 `tools/console/growth_api.py`（只读 helper，不注册路由）：`growth_narrative()`、`growth_status()`。

默认路径：
- DB：`agi/data/selflearn/selflearn.sqlite3`（`db.DB_PATH`；生产可传具体联系人 base）
- 周记：`agi/data/diary/weekly/YYYY-Wxx.md`
- 归档：`agi/data/selflearn/narrative_history.jsonl`（gitignore）
- 日记：`agi/data/diary/**/*.md`（P31 未落地时为空）
- 被否定：P30 `agi/data/train/daily/*.jsonl` 的 `quality=negative`

## 3. 周记与叙事

- 周记 prompt 要求：第一人称 300–500 字，具体、口语、不总结报告腔；写注意到什么/
  在意什么/哪里像人/哪里出戏/下周怎么改；不编造素材外事实。
- 叙事 prompt：从周记提炼 ≤120 字，第一人称，只写“我是谁/我在意什么/我正在怎么变化”。
- LLM 不可用/输出太短：规则兜底（`llm:"fallback"`），仍然写周记/叙事，不阻断。
- 周记 md：
  ```markdown
  # YYYY-Wxx 周记
  - 周期：... → ...
  - 对话轮次：... · 消息：...
  - 心情均值：...
  ## 周记
  ...
  ## 自我叙事
  ...
  ```
- 幂等：同一周 weekly md 已存在 → `{ok:true,skipped:true,reason:"week_exists"}`；
  `force=True` 才重跑。叙事与原值相同 → `changed:false`，不重复写 core。

## 4. core 层与归档

- 写入 `persona_layers`：`layer="core"`, `key="self_narrative"`；
  `observe` 后 `approve(approved_by="weekly_review")` → `status=active`。
- 写前取当前 active 值；不同则把旧值追加到 `narrative_history.jsonl`
  （字段：ts/week/old/new/reason）。
- 当前叙事只用于后续 chat 注入/控制台展示；**不自动改 chat 行为**（等 Lead OK 再接）。

## 5. 周任务与接线（本任务只准备，不改 chat/server/config）

### 5.1 gateway 周日 23:30（已准备 helper，等 server.py 空下来接 3 行）

`self_narrative.maybe_weekly(now=..., weekly_dir=..., enabled=<narrative_enabled>)`
返回：
```json
{"ok":true,"should_run":true,"reason":"due","week":"2026-W44",
 "due_at":"2026-11-01T23:30:00","next_run":"2026-11-08T23:30:00",
 "diary_path":".../weekly/2026-W44.md","weekly_exists":false}
```
- 每周日 23:30 到期；到期后本周 weekly md 不存在 → True；已存在 → already_ran；
  未到期 → not_due；开关关闭 → disabled；**函数本身不写文件**。
- gateway 线程建议逻辑：
  ```python
  check = self_narrative.maybe_weekly(enabled=cfg.get("narrative_enabled", False))
  if check["should_run"]:
      self_narrative.weekly_review()
  ```
  放在现有周日线程/定时器里即可，不需要改 chat。

### 5.2 chat `_system_prompt` 尾部注入（等 w2-inner/p0-crisis 改完再动）

调用点：`SelfLearnAgent._system_prompt`（或实际拼 system prompt 的函数）**return 前**：
```python
from . import self_narrative
line = self_narrative.inject_line(db_path=self.path)
if line:                      # 为空时一个字符都不加，原有 prompt 逐字节不变
    prompt = prompt.rstrip() + "\n\n" + line
```
- `inject_line` 已硬截 ≤80 字；无叙事返回 `""`。
- 建议放在尾部、但不要覆盖生产硬约束；此段只是"自我叙事"上下文。

### 5.3 console 两条只读 API（helper 已写好，接线等通知）

已新增 `tools/console/growth_api.py`（不注册路由、不改 server.py）：

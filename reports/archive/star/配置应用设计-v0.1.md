## 0. 一句话

给"另一台什么都没有的 Windows 电脑"准备一个**绿色免安装包**：解压 → 双击 → 跟着向导选能力档位、填 API Key → 一键完成配置并启动。

**核心判断：这不是一个独立外壳。** 项目里现有 15 处以上写死了 `E:\agent` / `C:\Python314` / `agi/data/wechat/.venv`。安装器必须建立在"路径解耦"之上，否则只是把硬编码从代码搬进 JSON，换机照样崩。**路径解耦是 P0 前置条件。**

## 1. 已锁定的四条决策

| # | 决策 | 选择 | 连锁影响 |
|---|---|---|---|
| D1 | 危险能力（读内存取密钥 / 解密 DB / 代替发送） | **向导里显式勾选，默认全关** | 必须引入"能力档位"（见 §2）；合规声明可按档位写且由代码强制 |
| D2 | 分发形态 | **绿色 zip，免安装免管理员** | 数据强制落 `%LOCALAPPDATA%\SoulAgent`，不写注册表（只读探测微信路径） |
| D3 | 向导技术 | **本地 Web 向导**（http.server + 复用 802 控制台样式） | 零新依赖；先决条件是包内自带运行时 |
| D4 | 本地模型默认档 | **纯 API（<100MB）** | 引导器不需要装 llama.cpp / CUDA / torch，体量与失败面大幅收缩 |

## 2. 能力档位（最重要的一节）

D1 的连锁：项目**收消息本身**就依赖 `wx_core/config.py:31` 的 `db_direct=True`（内存扫密钥 + WCDB 直读）。
所以"危险能力全关"不等于"少几个功能"，而是**微信网关 801 收不到消息**。必须拆档：

| 档 | 收消息方式 | 图片/表情 | 发送 | 默认 | 风险 | 依赖 |
|---|---|---|---|---|---|---|
| **A · 只读观察** | 截图 + OCR（`PrintWindow`，纯外部观察） | 聊天区高质量截图 | ❌ | ✅ | 最低 | base wheels |
| **B · 数据库直读** | + WCDB 解密（需读内存取密钥） | 原图 / 原 GIF | ❌ | 需勾选 | 中 | + db wheels |
| **C · 自动回复** | 同 B | 同 B | ✅ 但 `dry_run=true` + `send_mode=confirm` | 需勾选两次（再单独确认才转 `auto`） | 最高（ToS/封号） | + send wheels + wxauto4 venv |

**硬约束**：档 A 必须是能独立跑通的完整产品（只读镜像 8081 + 网页聊天 8082），不是残废版。
这样开源版第一天就有"零风险体验路径"，用户自己决定升不升档。

档位到配置的映射（写进 `setup.json`）：

| 档 | `features.send` | `features.db_direct` | `features.auto_reply` |
|---|---|---|---|
| A | false | false | false |
| B | false | true | false |
| C | true | true | false（再由控制台二次开启） |

## 3. 出厂布局（绿色 zip，~100MB）

```
SoulAgent-0.9.0-win64/
├─ 开始配置.bat                 ← 唯一入口，双击它
├─ runtime/python313/           ← python-build-standalone，解压即用，不写 PATH/注册表
├─ wheels/                      ← 预下载 wheel（按档位分组：base / db / send）
├─ bootstrap/                   ← 引导器 + 配置向导（独立，不 import 主项目）
│   ├─ app.py                   ← 起本地 Web 向导
│   ├─ detect.py                ← 环境探测
│   ├─ install.py               ← wheel / 运行时安装
│   ├─ models.py                ← 模型下载（断点续传 + SHA256）
│   ├─ doctor.py                ← 自检
│   ├─ supervise.py             ← 服务编排（启停/健康/退避重启/日志轮转）
│   ├─ manifest.json            ← 运行时/依赖/模型版本清单
│   └─ ui/                      ← 复用 802 控制台样式
├─ app/                         ← 主项目（agi/ tools/ wx_core/ webui/ …）
└─ README.md  LICENSE  NOTICE
```

体量估算：runtime ~40MB + wheels ~50MB + 代码 ~10MB ≈ **100MB**。
模型一律不打进包（纯 API 档不需要），首启时按需下。

**落地位置规则**
- 程序目录：用户解压到哪就是哪，只读为主。
- 用户数据：`%LOCALAPPDATA%\SoulAgent\`（或向导里让用户选）。
- 注册表：只读（探测微信安装路径），**绝不写**。
- 禁止写 `Program Files` / 禁止要管理员权限。

## 5. `manifest.json` —— 远程可更新，修 bug 不必重发安装包

示例见 `schemas/manifest.example.json`。

要点：
- `wheels` 按档位分组（A 只装 base，勾 C 才装 wxauto4 那组）。
- `models` 带 `size` / `sha256` / `optional` / `tier`，下载支持 Range 断点续传 + 校验。
- `compat.wechat` 做版本兼容矩阵；不在列表内 → 向导标"未验证"并允许继续（进降级模式）。
- `llama` 分 `cuda` / `cpu` 两套；仅在用户选了本地模型档时才需要。

## 6. 向导：5 页 + 一张自检表

| 页 | 内容 | 校验 / 副作用 |
|---|---|---|
| ① 欢迎 + 风险 | 版本、许可、`compat.wechat` 显示"实测 4.1.15.56" | 必须勾选风险声明 |
| ② 环境检测 | doctor 只读跑一遍 | 每项 ✅/⚠️/❌ + 一键修复 |
| ③ **能力档位** | A / B / C 单选；B、C 展开二次风险确认 | 写 `setup.json.features` |
| ④ 安装 | 装 wheel、可选下模型（断点续传 + SHA256）、起服务 | 实时日志 + 可暂停 |
| ⑤ 配置 + 自检 | DeepSeek Key（**实测校验**）、数据目录、端口、人格选择 | 全绿才允许"完成" |

### doctor 检查项（决定未来是否被 issue 淹没）

1. OS 版本 / 架构 / 磁盘剩余
2. Python 版本 + 关键 import（Pillow / numpy / pycryptodome / pywin32 / wxauto4）
3. 微信：安装路径 / 进程 / 主窗口句柄 / **版本** / 是否登录
4. 数据根定位 + **能否解密首页**（仅 B/C 档）
5. 模型：GGUF 存在 + SHA256；llama-server 可执行 + 健康（仅本地档）
6. 网络：`api.deepseek.com` TLS 可达；可选模型源可达
7. 端口：801/802/8081/8082 占用情况
8. **中文路径 / locale / 时区**（Windows Python 经典坑）
9. 权限：应当**不需要**管理员
10. **杀软拦截检测**（本程序含 UI 自动化 + 内存读取，必然被误报，需提前告知）

失败项统一提供："一键修复" 或 "复制脱敏诊断包"（Key / wxid / 联系人名一律 hash）。

## 7. 开工顺序（关键：不与在修的 bug 撞车）

作者当前正在修主项目（`wx_core` / `agi/wechat_gateway` / config）。因此**第一刀不碰主项目**。

建议先写 `bootstrap/` 这个独立目录：只通过 `setup.json` + 子进程与主项目耦合，零 import、零改主项目文件，可并行开发。

| 期 | 内容 | 判据 |
|---|---|---|
| **P0** | 数据/密钥剥离 + `.git` + 许可声明 + `setup.json` 路径解耦 + 修 requirements | 换一台干净机器能手工跑起来 |
| **P1** | 引导器（运行时 + wheel + 端口）+ `doctor.py` 自检 | 双击 .bat → 全绿 → 802 能开 |
| **P2** | 向导 5 页 + 三档位 + DPAPI 存 Key + supervisor | 非技术用户能独立装完 |
| **P3** | manifest 远程更新 / 修复 / 出厂重置 / 脱敏诊断包 / CI | 作者不在场也能维护 |

**推荐起步：`doctor.py`** —— 只读、零风险、可立刻验证，且在修 bug 期间还能当调试工具。

## 8. 明确不做

- ❌ PyInstaller onefile 打包全项目（自解压到 temp，最容易被杀软误报；叠加内存读取基本必报）
- ❌ MSI/NSIS 装进 `Program Files`（要管理员权限，数据目录还得另选）
- ❌ 把模型打进安装包（2GB+，更新即全量重下）
- ❌ 开机自启 / 注册系统服务（一个会替你发微信的程序自启，用户会恐慌）
- ❌ 加壳 / UPX（杀软误报放大器）
